RADR bietet Zugriff auf die integrierten Strichmuster des OSSM. Muster werden direkt von Ihrem OSSM geladen, wenn Sie eine Verbindung herstellen. Die verfügbaren Muster hängen daher von der Firmware-Version Ihres OSSM ab.

![RADR pattern-selection screen with the highlighted pattern, its motion description, and select and back actions](<../../img/image (3).webp>)

<Callout type="warn" title="Ändern Sie Muster bei Nullgeschwindigkeit">

Stellen Sie die Geschwindigkeit wieder auf Null, bevor Sie ein anderes Muster auswählen. Bestätigen Sie den markierten Namen und beginnen Sie erneut mit niedriger Geschwindigkeit; Musternamen und Verhalten können sich mit der angeschlossenen OSSM-Firmware ändern.

</Callout>

## Auf Muster zugreifen

So greifen Sie auf den Mustermodus zu:

1. Verbinden Sie sich mit Ihrem OSSM
2. Drücken Sie auf dem Steuerbildschirm die **rechte Taste (Muster)**
3. Verwenden Sie den **rechten Encoder**, um durch die verfügbaren Muster zu scrollen
4. Drücken Sie die **rechte Taste**, um ein Muster auszuwählen
5. Drücken Sie die **linke Taste**, um abzubrechen, ohne Änderungen vorzunehmen

<Callout type="info">

Muster werden von Ihrem OSSM geladen, wenn Sie eine Verbindung herstellen. Die Musterliste kann je nach Firmware-Version Ihres OSSM variieren.

</Callout>
## Steuerelemente im Mustermodus

| Kontrolle | Aktion |
| ------------- | ----------------------------------- |
| Rechter Encoder | Durch Muster scrollen |
| Linker Encoder | Geschwindigkeit anpassen (funktioniert immer noch) |
| Rechter Knopf | Wählen Sie das hervorgehobene Muster | aus
| Linke Taste | Abbrechen und zum Kontrollbildschirm zurückkehren |
| Mittlerer Knopf | Anhalten und zum Kontrollbildschirm zurückkehren |

<Callout type="idea">

Die Geschwindigkeitsregelung (linker Encoder) funktioniert im Pattern-Modus weiterhin, sodass Sie die Intensität beim Durchsuchen von Patterns anpassen können.

</Callout>
## Verfügbare Muster

RADR zeigt alle Muster an, die auf Ihrem angeschlossenen OSSM verfügbar sind. Das Musterverhalten hängt von der Firmware-Version Ihres OSSM ab. In der Beschreibung auf dem Bildschirm wird erklärt, wie sich der Empfindungsparameter auf jedes Muster auswirkt.

Auf dieser Seite wird zusammengefasst, wie Sie auf Muster wie Simple Stroke, Teasing or Pounding, Robo Stroke, Half'n'Half, Deeper, Stop'n'Go, Insist und mehr zugreifen und diese verwenden können.

| Von RADR | gezeigte Musterfamilie Allgemeine Bewegungscharakteristik | Was Sie überprüfen sollten, bevor Sie die Geschwindigkeit erhöhen |
| ------------- | --------------------------------------------------------- | ------------------------------------------------------------------- |
| Einfacher Strich | Regelmäßiger Hin- und Herschlag | Strichbereich und -tiefe passen zur Anzeige |
| Necken / Hämmern | Bewegungscharakter ändert sich mit der Empfindungssteuerung | Die niedrige Einstellung verhält sich wie erwartet, bevor eine stärkere Einstellung ausprobiert wird |
| Robo Stroke | Mechanisch regelmäßige Variation | Übergänge überschreiten nicht den vorgesehenen Bereich |
| Halb und halb | Wechselt zwischen zwei Bewegungsabschnitten | Beide Abschnitte bleiben innerhalb des ausgewählten Bereichs |
| Tiefer | Verzerrt die Bewegung zum tieferen Ende des ausgewählten Bereichs | Der tiefste Punkt bleibt klar und komfortabel |
| Stop'n'Go | Enthält absichtliche Pausen | Eine programmierte Pause ist nicht mit einer nicht verbundenen Steuerung zu verwechseln |
| Bestehen Sie | Wiederholt oder betont einen Teil des Strichs | Wiederholung bleibt innerhalb der vorgesehenen Position und Reichweite |

Dabei handelt es sich um Orientierungsbeschreibungen, nicht um feste Bewegungsvorgaben. Der verbundene OSSM stellt die maßgebliche Musterimplementierung bereit. Wenn das Verhalten auf dem Bildschirm von dieser Tabelle abweicht, halten Sie an und notieren Sie sich beide Firmware-Versionen und [contact support](mailto:support@researchanddesire.com).

## Tipps

<Callout type="idea">

Muster funktionieren in Kombination mit Ihrer Geschwindigkeitseinstellung. Ein Muster bei 20 % Geschwindigkeit fühlt sich ganz anders an als dasselbe Muster bei 80 % Geschwindigkeit. Experimentieren Sie mit verschiedenen Kombinationen.

</Callout>
<Callout type="idea">

Beginnen Sie mit **Einfacher Strich**, um sich mit der Steuerung vertraut zu machen, und experimentieren Sie dann mit anderen Mustern.

</Callout>
<Callout type="idea">

Neue Muster können durch Firmware-Updates für OSSM hinzugefügt werden. Suchen Sie nach Firmware-Updates, um auf die neuesten Musterbibliotheken zuzugreifen.

</Callout>
