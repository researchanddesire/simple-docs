RADR bietet Zugriff auf die integrierten Hubmuster des OSSM. Die Muster
werden direkt von Ihrem OSSM geladen, sobald Sie eine Verbindung herstellen.
Die verfügbaren Muster hängen daher von der Firmware-Version Ihres OSSM ab.

![RADR-Bildschirm zur Musterauswahl mit dem hervorgehobenen Muster, seiner Bewegungsbeschreibung sowie den Aktionen zum Auswählen und Zurückkehren](<../../img/image (3).webp>)

<Callout type="warn" title="Muster bei null Geschwindigkeit wechseln">

Setzen Sie die Geschwindigkeit auf null zurück, bevor Sie ein anderes Muster
auswählen. Bestätigen Sie den hervorgehobenen Namen und beginnen Sie erneut mit
niedriger Geschwindigkeit. Musternamen und Verhalten können sich mit der
angeschlossenen OSSM-Firmware ändern.

</Callout>

## Auf Muster zugreifen

So greifen Sie auf den `Pattern Mode` zu:

1. Verbinden Sie sich mit Ihrem OSSM
2. Drücken Sie auf dem Steuerbildschirm die **rechte Taste (`Patterns`)**
3. Verwenden Sie den **rechten Encoder**, um durch die verfügbaren Muster zu scrollen
4. Drücken Sie die **rechte Taste**, um ein Muster auszuwählen
5. Drücken Sie die **linke Taste**, um abzubrechen, ohne Änderungen vorzunehmen

<Callout type="info">

Die Muster werden von Ihrem OSSM geladen, sobald Sie eine Verbindung herstellen.
Die Musterliste kann je nach Firmware-Version Ihres OSSM variieren.

</Callout>
## Steuerelemente im `Pattern Mode`

| Bedienelement | Aktion |
| ------------- | ----------------------------------- |
| Rechter Encoder | Durch Muster scrollen |
| Linker Encoder | Geschwindigkeit anpassen (weiterhin verfügbar) |
| Rechte Taste | Hervorgehobenes Muster auswählen |
| Linke Taste | Abbrechen und zum Steuerbildschirm zurückkehren |
| Mittlere Taste | Pausieren und zum Steuerbildschirm zurückkehren |

<Callout type="idea">

Die Geschwindigkeitsregelung (linker Encoder) funktioniert auch im `Pattern Mode`
weiterhin, sodass Sie die Intensität beim Durchsuchen von Mustern anpassen können.

</Callout>
## Verfügbare Muster

RADR zeigt alle Muster an, die auf Ihrem angeschlossenen OSSM verfügbar sind. Das
Musterverhalten hängt von der Firmware-Version Ihres OSSM ab. In der Beschreibung
auf dem Bildschirm wird erklärt, wie sich der Parameter `Sensation` auf jedes
Muster auswirkt.

Auf dieser Seite wird zusammengefasst, wie Sie auf Muster wie Simple Stroke,
Teasing or Pounding, Robo Stroke, Half'n'Half, Deeper, Stop'n'Go, Insist und mehr
zugreifen und diese verwenden können.

| Von RADR gezeigte Musterfamilie | Allgemeine Bewegungscharakteristik | Was Sie überprüfen sollten, bevor Sie die Geschwindigkeit erhöhen |
| ------------- | --------------------------------------------------------- | ------------------------------------------------------------------- |
| Simple Stroke | Regelmäßige Hin-und-her-Bewegung | `Stroke`-Bereich und Tiefe stimmen mit der Anzeige überein |
| Teasing / Pounding | Der Bewegungscharakter ändert sich mit der `Sensation`-Steuerung | Die niedrige Einstellung verhält sich wie erwartet, bevor eine stärkere Einstellung ausprobiert wird |
| Robo Stroke | Mechanisch regelmäßige Variation | Übergänge überschreiten nicht den vorgesehenen Bereich |
| Half'n'Half | Wechselt zwischen zwei Bewegungsabschnitten | Beide Abschnitte bleiben innerhalb des ausgewählten Bereichs |
| Deeper | Verlagert die Bewegung zum tieferen Ende des ausgewählten Bereichs | Der tiefste Punkt bleibt eindeutig und komfortabel |
| Stop'n'Go | Enthält absichtliche Pausen | Eine programmierte Pause ist nicht mit einem getrennten Controller zu verwechseln |
| Insist | Wiederholt oder betont einen Teil des Hubs | Die Wiederholung bleibt innerhalb der vorgesehenen Position und des vorgesehenen Bereichs |

Dabei handelt es sich um Orientierungsbeschreibungen, nicht um feste
Bewegungsvorgaben. Der verbundene OSSM stellt die maßgebliche
Musterimplementierung bereit. Wenn das Verhalten auf dem Bildschirm von dieser
Tabelle abweicht, stoppen Sie den OSSM, notieren Sie beide Firmware-Versionen und
[kontaktieren Sie den Support](https://www.researchanddesire.com/pages/contact-us).

## Tipps

<Callout type="idea">

Muster funktionieren in Kombination mit Ihrer Geschwindigkeitseinstellung. Ein Muster bei 20 % Geschwindigkeit fühlt sich ganz anders an als dasselbe Muster bei 80 % Geschwindigkeit. Experimentieren Sie mit verschiedenen Kombinationen.

</Callout>
<Callout type="idea">

Beginnen Sie mit **Simple Stroke**, um sich mit der Steuerung vertraut zu machen,
und experimentieren Sie dann mit anderen Mustern.

</Callout>
<Callout type="idea">

Neue Muster können durch OSSM-Firmware-Updates hinzugefügt werden. Suchen Sie nach OSSM-Firmware-Updates, um auf die neuesten Musterbibliotheken zuzugreifen.

</Callout>
