---
title: "Update RADR Firmware"
description: "Prepare for a RADR firmware update, verify the installed result, and recover safely from an interrupted update."
---

The firmware version appears during RADR startup. This documentation does not publish a “latest” version because the release manifest can change independently; the updater or [Web Flasher](/radr/tools/web-flasher) shows the version it is prepared to install.

## Before updating

1. Stop and disconnect the controlled device. Do not update during a session.
2. Note the current firmware version shown at startup and any device-specific settings you may need to recreate.
3. Charge RADR and keep it connected to stable power for the update.
4. For an over-the-air update, first [connect RADR to Wi-Fi](/radr/guides/user-guide/connecting-to-wifi).
5. Do not begin unless you can leave RADR powered on and nearby until it restarts.

<Callout type="warn" title="Settings preservation and rollback are not guaranteed">

The repository does not provide a version-by-version settings-migration or rollback guarantee. Record important settings before updating. Install an older image only when the flasher offers it and support has confirmed that downgrade is appropriate.

</Callout>

## Update over the air

1. From the main menu, select **Settings**.
2. Select **Update Device**.
3. Leave RADR powered on while it checks, downloads, installs, and restarts.
4. After restart, note the version shown on the startup screen.
5. Open the settings and device scan to confirm normal operation.
6. Reconnect the target device unloaded, start at its lowest output, and verify Stop.

The update is successful only after RADR restarts normally and displays the expected version. Do not infer success merely because the progress screen disappeared.

## If the update fails

| Symptom                                          | Action                                                                                              |
| ------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| Check or download fails before installation      | Confirm 2.4 GHz Wi-Fi and internet access, restart RADR, and retry once                             |
| Progress stops and RADR remains responsive       | Keep power connected and wait for the on-screen state to change; do not repeatedly power-cycle it   |
| RADR restarts but reports the old version        | Record both versions and the message, then contact support before retrying repeatedly               |
| RADR will not start normally                     | Connect stable USB power and use the [RADR Web Flasher](/radr/tools/web-flasher) recovery procedure |
| A connected device behaves differently afterward | Stop, power down the target device, and report both firmware versions                               |

For an unrecoverable result, email [support@researchanddesire.com](mailto:support@researchanddesire.com) with the prior version, attempted version, browser or update method, and the last visible message.
