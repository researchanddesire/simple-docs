From the main menu, select **Settings** with the right encoder and right button. Use the left button to return.

| Menu item      | Purpose                                                     | Procedure                                                            |
| -------------- | ----------------------------------------------------------- | -------------------------------------------------------------------- |
| Go Back        | Return to the main menu                                     | —                                                                    |
| Wi-Fi Settings | Open the temporary setup network and save a 2.4 GHz network | [Connect RADR to Wi-Fi](/radr/guides/user-guide/connecting-to-wifi)  |
| Update Device  | Check for and install an over-the-air firmware update       | [Update RADR Firmware](/radr/guides/user-guide/updating-your-device) |
| Restart Device | Reboot RADR and reset its current Bluetooth session         | Confirm the controlled device has stopped first                      |

Wi-Fi is used for network features such as updates; direct device control uses Bluetooth. This reference deliberately does not repeat network credentials or update steps, so the linked canonical procedures remain the single source of truth.

## Sleep and power

Choose **Sleep** from the main menu to disconnect the current device, turn off the display and LEDs, and enter the low-power state. An under-screen button wakes RADR and returns it through startup.

Use the physical power switch for extended storage. Before sleep, restart, or power-off, stop the connected device and verify it is physically stationary; a remote changing state is not a substitute for powering down a device that is behaving unexpectedly.

If RADR will not wake, connect it to power, try the physical power switch, and then use the [RADR Web Flasher](/radr/tools/web-flasher) only if the firmware-recovery prerequisites apply.
