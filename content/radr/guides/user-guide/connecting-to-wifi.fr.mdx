La connectivité Wi-Fi permet à votre télécommande sans fil (RADR) Research And Desire de recevoir des mises à jour sans fil, y compris la prise en charge de nouveaux appareils et des corrections de bugs. Ce guide vous guide à travers le processus de configuration simple.

## Pourquoi se connecter à Wi-Fi ?

La connexion de votre RADR à Wi-Fi permet :

- **Mises à jour en direct** — Obtenez les derniers micrologiciels et fonctionnalités sans câbles
- **Prise en charge des nouveaux appareils** — Recevez des mises à jour qui ajoutent la compatibilité avec les nouveaux appareils Bluetooth
- **Corrections de bugs** — Restez informé des dernières améliorations

<Callout type="info">

Wi-Fi est facultatif pour une utilisation de base. RADR contrôle entièrement les appareils via Bluetooth, vous pouvez donc l'utiliser sans Wi-Fi. Cependant, nous vous recommandons de vous connecter pour recevoir les mises à jour.

</Callout>
## Avant de commencer

Assurez-vous d'avoir :

- Le nom et le mot de passe de votre réseau Wi-Fi domestique
- Un téléphone ou une tablette pour scanner le QR code (ou vous pouvez vous connecter manuellement)
- Votre RADR chargé et allumé

<Callout type="warn">

RADR prend uniquement en charge les réseaux Wi-Fi 2,4 GHz. Si votre routeur diffuse à la fois 2,4 GHz et 5 GHz, assurez-vous de vous connecter au réseau 2,4 GHz.

</Callout>
## Connexion à Wi-Fi

### Étape 1 : Ouvrez les paramètres Wi-Fi

Depuis le menu principal de votre RADR :

1. Sélectionnez **Paramètres** à l'aide du bouton droit et du bouton droit.
2. Sélectionnez **Wi-Fi Paramètres**

Votre RADR créera son propre réseau temporaire Wi-Fi pour la configuration.

![RADR Settings menu with Wi-Fi Settings available](../../../ossm/images/wireless-remote-wifi-connectivity-settings-unannotated.webp)

### Étape 2 : Connectez-vous au réseau de configuration de RADR

Un QR code apparaît sur l'écran de votre RADR. Vous avez deux options :

![RADR displaying the QR code for its temporary setup network](../../../ossm/images/wireless-remote-wifi-connectivity-wifi-qr-code-unannotated.webp)

**Option A : Scannez le code QR (le plus simple)**

Utilisez l'appareil photo de votre téléphone pour scanner le QR code. Votre téléphone se connectera automatiquement au réseau de configuration de RADR.

**Option B : connexion manuelle**

Sur votre téléphone ou votre tablette, accédez aux paramètres Wi-Fi et connectez-vous à :

- **Nom du réseau :** Configuration RADR
- **Mot de passe :** Aucun (réseau ouvert)

### Étape 3 : Entrez vos détails Wi-Fi

Une fois connecté au réseau de configuration de RADR, une page de configuration s'ouvre automatiquement dans votre navigateur.

<Callout type="idea">

Si la page ne s'ouvre pas automatiquement, ouvrez votre navigateur et accédez à **192.168.4.1**

</Callout>
Sur la page de configuration :

1. Sélectionnez votre réseau domestique Wi-Fi dans la liste
2. Entrez votre mot de passe Wi-Fi
3. Appuyez sur **Enregistrer**

![Setup portal showing the 2.4 GHz network list and password field](../../../ossm/images/radr-wifi-network-selection-annotated.webp)

### Étape 4 : Attendez la confirmation

RADR se connectera à votre réseau Wi-Fi. En cas de succès, vous verrez :

**"Wi-Fi Connecté"** sur l'écran

Votre RADR est maintenant prêt à recevoir des mises à jour !

## Dépannage

<Callout type="info" title="La page de configuration ne s'ouvre pas">

- Assurez-vous que vous êtes connecté à "RADR Setup" (vérifiez les paramètres Wi-Fi de votre téléphone)
- Essayez d'ouvrir un navigateur et d'accéder à **192.168.4.1**
- Attendez quelques secondes après la connexion — la page peut prendre un moment à se charger
- Si la page n'apparaît toujours pas, redémarrez les paramètres Wi-Fi sur votre RADR et réessayez

</Callout>
<Callout type="info" title="Mon réseau Wi-Fi n'est pas dans la liste">

- Rapprochez-vous de votre routeur Wi-Fi
- Assurez-vous de rechercher votre réseau **2,4 GHz** (et non 5 GHz)
- Essayez de rafraîchir la page
- Redémarrez les paramètres Wi-Fi et numérisez à nouveau

</Callout>
<Callout type="info" title="La connexion échoue après avoir entré le mot de passe">

- Vérifiez à nouveau que vous avez entré le bon mot de passe
- Assurez-vous d'avoir sélectionné le bon réseau
- Rapprochez RADR de votre routeur
- Vérifiez que votre routeur fonctionne (essayez de connecter un autre appareil)

</Callout>
<Callout type="info" title="La configuration expire avant que je puisse me connecter">

Le portail de configuration Wi-Fi a un délai d'attente de 30 secondes. S'il se ferme avant que vous ayez terminé :

1. Revenez à **Paramètres > Wi-Fi Paramètres** sur votre RADR
2. Le processus de configuration redémarrera
3. Préparez votre mot de passe Wi-Fi pour pouvoir le saisir rapidement

</Callout>
<Callout type="info" title="Je me suis connecté mais RADR dit qu'il n'est pas en ligne">

- Vérifiez que votre domicile Wi-Fi a accès à Internet
- Essayez de redémarrer votre RADR (Paramètres > Redémarrer l'appareil)
- Réexécutez le processus de configuration Wi-Fi

</Callout>
