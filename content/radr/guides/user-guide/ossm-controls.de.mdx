In dieser Anleitung erfahren Sie, wie Sie den OSSM (Open Source Sex Machine) mit Ihrer RADR-Funkfernbedienung steuern.

<Callout type="warn" title="Stopp vor der Verwendung überprüfen">

Lassen Sie den OSSM unbelastet, stellen Sie die Geschwindigkeit auf null und
testen Sie sowohl `Pause` mit einem Druck als auch `Full Stop` mit zwei Drücken,
bevor Sie ein Zubehör anbringen oder eine Sitzung beginnen. `Pause` behält die
aktuellen Einstellungen bei; `Full Stop` setzt sie zurück. Wenn eine der beiden
Aktionen die physische Bewegung nicht stoppt, schalten Sie den OSSM aus und
verwenden Sie [Fehlerbehebung](/ossm/troubleshooting).

</Callout>

## Übersicht über den Kontrollbildschirm

Bei Anschluss an einen OSSM zeigt der Steuerbildschirm Folgendes an:

- **Oben:** Drei Registerkarten mit den Modi `Depth`, `Sensation` und `Stroke`
- **Obere Bumper:** Tasten `<<` und `>>` zum Umschalten des Modus
- **Linke Seite:** Geschwindigkeits-Encoder mit Bogenanzeige
- **Rechte Seite:** Modus-Encoder (Depth/Sensation/Stroke) mit Bogenanzeige
- **Mitte:** Lineares Schienendiagramm mit Visualisierung von `Stroke` und `Depth`
- **Unter dem Diagramm:** Aktueller Mustername
- **Unten:** `Menu`-, `Pause`- und `Patterns`-Tasten

## Geschwindigkeitssteuerung

Der **linke Encoder** steuert immer die Geschwindigkeit, unabhängig davon, welcher Modus aktiv ist.

| Parameter | Bereich | Standard |
| --------- | ------ | ------- |
| Speed | 0–100% | 0% |

- Im Uhrzeigersinn drehen, um die Geschwindigkeit zu erhöhen
- Gegen den Uhrzeigersinn drehen, um die Geschwindigkeit zu verringern
- Der Encoder verfügt über eine Beschleunigung: Schnellere Drehungen führen zu größeren Änderungen

<Callout type="info">

Damit sich der OSSM bewegen kann, muss `Speed` über 0% liegen. Erhöhen Sie bei
`Pause` die Geschwindigkeit, um automatisch fortzufahren.

</Callout>
## Anpassungsmodi

Der **rechte Encoder** steuert einen von drei Parametern, je nachdem, welcher Modus aktiv ist. Verwenden Sie die Bumper, um den Modus zu wechseln.

### Tiefenmodus

Steuert, wie tief die Penetration reicht.

| Parameter | Bereich | Standard |
| --------- | ------ | ------- |
| Depth | 0–100% | 10% |

- Höhere Werte = tiefere Eindringtiefe
- Die Tiefe wird im linearen Schienendiagramm visualisiert

### Sensation-Modus

Steuert die Intensität oder das „Gefühl“ der Bewegung.

| Parameter | Bereich | Standard |
| --------- | ------ | ------- |
| Sensation | 0–100% | 50% |

- Niedrigere Werte = sanftere, gleichmäßigere Bewegung
- Höhere Werte = intensivere, aggressivere Bewegung

### Stroke-Modus

Steuert die Länge jedes Hubs.

| Parameter | Bereich | Standard |
| --------- | ------ | ------- |
| Stroke | 0–100% | 50% |

- Niedrigere Werte = kürzere Hübe
- Höhere Werte = längere Hübe
- `Stroke` wird im linearen Schienendiagramm visualisiert

## Modi wechseln

Sie haben zwei Möglichkeiten, zwischen `Depth`, `Sensation` und `Stroke` zu wechseln:

### Verwendung der Bumper (empfohlen)

- **Linker Bumper (`<<`)** – Wechseln Sie zum vorherigen Modus
- **Rechter Bumper (`>>`)** – Wechseln Sie zum nächsten Modus

Die Modusreihenfolge ist: `Depth` → `Sensation` → `Stroke` → `Depth` ...

### Visuelles Feedback

Wenn Sie den Modus wechseln:

- Die entsprechende Registerkarte oben wird hervorgehoben
- Die Farbe der rechten Encoder-LED ändert sich:
  - **Koralle/Rot** – Tiefenmodus
  - **Blau** – Sensation-Modus
  - **Grün** – Stroke-Modus
- Die linke Encoder-LED bleibt **Violett** (immer Geschwindigkeit)

## Pause und Stopp

Die **mittlere Taste** steuert Pause und Stopp.

### Einmaliges Drücken: Pause

Durch einmaliges Drücken wird der OSSM pausiert:

- `Speed` ist auf 0% eingestellt
- Der Mustername wechselt zu `Paused` und wird rot dargestellt.
- Die mittlere LED leuchtet rot
- Die Taste `Pause` wechselt zu `STOP` (rot)

<Callout type="info">

Um aus der Pause fortzufahren, erhöhen Sie einfach die Geschwindigkeit mit dem linken Encoder. Der OSSM setzt den Betrieb automatisch fort.

</Callout>
### Sicherheitsfunktion: Permanente Geschwindigkeitsüberwachung

Wenn Sie `Pattern Mode` oder andere Menüs aufrufen, überwacht RADR aus
Sicherheitsgründen weiterhin den linken Encoder (`Speed`). Das bedeutet:

- Sie können die Geschwindigkeit beim Durchsuchen von Mustern weiterhin anpassen
- Wenn Sie die Geschwindigkeit auf 0 drehen, stoppt der OSSM sofort
- Dies stellt sicher, dass Sie immer über die Möglichkeit eines sofortigen Stopps verfügen

<Callout type="idea">

Auch beim Auswählen von Mustern steuert der linke Encoder die Geschwindigkeit. Dies ist eine Sicherheitsfunktion, kein Fehler.

</Callout>
### Doppeltes Drücken: Vollständiger Stopp

Durch kurzes Doppeldrücken wird ein Vollstopp mit Reset durchgeführt:

- `Speed` ist auf 0% eingestellt
- `Depth` wird auf 0% zurückgesetzt
- `Stroke` wird auf 10% zurückgesetzt
- `Sensation` wird auf 50% zurückgesetzt
- Der Bestätigungsbildschirm `Device Stopped` wird angezeigt

<Callout type="warn">

`Full Stop` setzt Ihre Anpassungseinstellungen zurück. Wenn Sie pausieren
möchten, ohne Ihre Einstellungen zu verlieren, verwenden Sie `Pause` mit einem
einzigen Tastendruck.

</Callout>
## Pattern Mode

Drücken Sie die **rechte Taste (`Patterns`)**, um in `Pattern Mode` zu gelangen.

Im Mustermodus:

- Der Bildschirm zeigt eine Liste der verfügbaren Muster
- Verwenden Sie den rechten Encoder, um durch die Muster zu scrollen
- Drücken Sie die rechte Taste, um ein Muster auszuwählen
- Drücken Sie die linke Taste, um abzubrechen und zurückzukehren

Einzelheiten zu den einzelnen Mustern finden Sie unter [Hubmuster](/radr/guides/user-guide/stroke-patterns).

## Lineares Schienendiagramm

Das lineare Schienendiagramm in der Mitte des Bildschirms bietet eine visuelle Darstellung der Bewegung des OSSM:

- Die Grafik zeigt den `Stroke`-Bereich und die `Depth`-Position
- Wenn Sie `Stroke` und `Depth` anpassen, wird die Visualisierung in Echtzeit aktualisiert
- Dies hilft Ihnen, die physische Bewegung zu verstehen, ohne auf die Maschine zu schauen

## Menütaste

Die **linke Taste (`Menu`)** ist für zukünftige OSSM-Geräteeinstellungen reserviert.

<Callout type="info">

Die Taste `Menu` ist derzeit deaktiviert und hat keine Funktion. Der Stil der
Taste ändert sich bei einer Pause (sie wirkt dann aktiviert), aber das Drücken
hat keine Auswirkung. Zukünftige Firmware-Updates werden über diese Taste
gerätespezifische Einstellungen ermöglichen.

</Callout>
## LED-Anzeigen während der Steuerung

| LED | Farbe | Bedeutung |
| ------------ | --------- | -------------------------- |
| Links (`Speed`) | Violett | Geschwindigkeitsmodus (immer aktiv) |
| Mitte | Weiß | Aktiv und läuft |
| Mitte | Rot | Pausiert oder gestoppt |
| Rechts (`Mode`) | Koralle/Rot | Tiefenmodus aktiv |
| Rechts (`Mode`) | Blau | Sensation-Modus aktiv |
| Rechts (`Mode`) | Grün | Stroke-Modus aktiv |

## Kurzreferenz

| Steuerung | Aktion |
| ------------- | ------------------------------------------ |
| Linker Encoder | Geschwindigkeit anpassen (0–100%) |
| Rechter Encoder | Aktiven Modus anpassen (0–100%) |
| Linker Bumper | Vorheriger Modus (`Depth` ← `Sensation` ← `Stroke`) |
| Rechter Bumper | Nächster Modus (`Depth` → `Sensation` → `Stroke`) |
| Linke Taste | `Menu` (deaktiviert) |
| Mittlere Taste | Einzeln: `Pause` / Doppelt: `Full Stop` |
| Rechte Taste | `Pattern Mode` öffnen |

## Tipps

<Callout type="idea">

Beginnen Sie mit niedriger Geschwindigkeit und steigern Sie diese schrittweise, um Ihre bevorzugte Intensität zu finden.

</Callout>
<Callout type="idea">

Verwenden Sie die Bumper, um den Modus nach Gefühl zu wechseln – Sie müssen
nicht auf den Bildschirm schauen.

</Callout>
<Callout type="idea">

Wenn Sie versehentlich einen Vollstopp ausführen, machen Sie sich keine Sorgen – passen Sie einfach Ihre Einstellungen neu an und erhöhen Sie die Geschwindigkeit, um fortzufahren.

</Callout>
