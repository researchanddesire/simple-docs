---
title: „Öffnen Sie den RADR Web Flasher“
description: „Öffnen Sie den funktionierenden RADR-Browser-Flasher und überprüfen Sie dessen USB, Browser-, Wiederherstellungs- und Verifizierungsanforderungen.“
---

Der RADR Web Flasher wurde in den Tools-Bereich des Geräts verschoben.

<Callout type="info" title="Verwenden Sie Chrome oder Edge auf einem Desktop-Computer">

Öffnen Sie das dedizierte [RADR Web Flasher](/radr/tools/web-flasher), um Firmware direkt von Ihrem Browser über USB-C zu installieren oder wiederherzustellen.

</Callout>

Die meisten Updates können auch drahtlos über **Einstellungen → Gerät aktualisieren** installiert werden. Weitere Informationen finden Sie unter [Updating Your Device](/radr/guides/user-guide/updating-your-device).
