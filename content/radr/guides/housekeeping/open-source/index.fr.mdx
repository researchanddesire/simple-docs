## Signaler un problème ou contribuer

- Recherchez [existing issues](https://github.com/researchanddesire/radr-wireless-remote/issues) avant d'en ouvrir un nouveau.
- Incluez la version du micrologiciel RADR, le modèle de l'appareil connecté, les étapes à reproduire et le résultat attendu.
- Suivez le [contribution guide](https://github.com/researchanddesire/radr-wireless-remote/blob/main/CONTRIBUTING.md) du référentiel pour les modifications de code ou de matériel.
- Utilisez le [Developer Docs contribution guide](https://developers.researchanddesire.com/contributing) pour le flux de travail et les normes de documentation.

Cette page est le répertoire destiné aux utilisateurs. Les fichiers de conception, les détails de construction et les instructions de contribution se trouvent dans la documentation liée de l'assembly et du développeur au lieu d'être dupliqués ici.
