## Report a problem or contribute

- Search [existing issues](https://github.com/researchanddesire/radr-wireless-remote/issues) before opening a new one.
- Include the RADR firmware version, connected-device model, steps to reproduce, and the result you expected.
- Follow the repository's [contribution guide](https://github.com/researchanddesire/radr-wireless-remote/blob/main/CONTRIBUTING.md) for code or hardware changes.
- Use the [Developer Docs contribution guide](https://developers.researchanddesire.com/contributing) for documentation workflow and standards.

This page is the user-facing directory. Design files, build details, and contribution instructions live in the linked assembly and developer documentation instead of being duplicated here.
