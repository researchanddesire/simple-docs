## Melden Sie ein Problem oder leisten Sie einen Beitrag

- Suchen Sie nach [existing issues](https://github.com/researchanddesire/radr-wireless-remote/issues), bevor Sie ein neues öffnen.
- Geben Sie die RADR-Firmware-Version, das Modell des angeschlossenen Geräts, die Schritte zur Reproduktion und das erwartete Ergebnis an.
- Befolgen Sie die [contribution guide](https://github.com/researchanddesire/radr-wireless-remote/blob/main/CONTRIBUTING.md) des Repositorys für Code- oder Hardwareänderungen.
- Verwenden Sie den [Developer Docs contribution guide](https://developers.researchanddesire.com/contributing) für Dokumentationsworkflows und Standards.

Diese Seite ist das für den Benutzer sichtbare Verzeichnis. Designdateien, Build-Details und Beitragsanweisungen befinden sich in der verknüpften Baugruppen- und Entwicklerdokumentation, anstatt hier dupliziert zu werden.
