# Device Tools

Choose a device to install or recover firmware directly over USB. Each device has a dedicated flasher in its Tools section.

<Callout type="warn" title="Use a supported desktop browser">

Use Chrome or Edge with a data-capable USB cable and stable power. Web Serial is not available in Safari, Firefox, or mobile browsers. Flash only when instructed by Research and Desire support.

</Callout>
