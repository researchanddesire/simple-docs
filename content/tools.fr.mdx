Choisissez un appareil pour installer ou récupérer le micrologiciel directement via USB. Chaque appareil dispose d'un clignotant dédié dans sa section Outils.

<Callout type="warn" title="Utilisez un navigateur de bureau pris en charge">

Utilisez Chrome ou Edge avec un câble USB compatible données et une alimentation stable. Web Serial n'est pas disponible dans Safari, Firefox ou les navigateurs mobiles. Flash uniquement lorsque le support Research and Desire vous le demande.

</Callout>
