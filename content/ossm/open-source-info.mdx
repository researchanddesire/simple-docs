OSSM hardware and software are developed openly. User setup and safety stay on this site; build instructions and technical implementation live in their dedicated documentation.

## Official destinations

| Resource                        | Destination                                                                                                              |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Source repository               | [researchanddesire/ossm](https://github.com/researchanddesire/ossm)                                                      |
| Hardware source files           | [`hardware/` in the OSSM repository](https://github.com/researchanddesire/ossm/tree/main/hardware)                       |
| Product bill of materials       | [Assembly BOM](https://ohai.researchanddesire.com/ossm/bom)                                                              |
| Build instructions              | [OSSM Assembly](https://ohai.researchanddesire.com/ossm/assembly-guide)                                                  |
| PCB reference                   | [OSSM hardware developer docs](https://dev.researchanddesire.com/ossm/hardware/pcb/introduction)                         |
| Firmware and software reference | [OSSM software developer docs](https://dev.researchanddesire.com/ossm/software/getting-started/introduction)             |
| Safety features in firmware     | [Developer safety-feature reference](https://dev.researchanddesire.com/ossm/software/getting-started/safety-features)    |
| License                         | [CERN Open Hardware Licence Version 2 — Strongly Reciprocal](https://ohwr.org/cern_ohl_s_v2.txt)                         |
| Issues and bug reports          | [OSSM GitHub issues](https://github.com/researchanddesire/ossm/issues)                                                   |
| Contribution guidance           | [Developer documentation contribution guide](https://dev.researchanddesire.com/ossm/software/contributing/documentation) |

<Callout type="warn" title="Modified hardware or firmware changes the safety case">

Re-run the unloaded homing, minimum-motion, and Stop tests after any change. A community modification is not automatically tested or supported by Research and Desire; review its source, license, known issues, and maintenance status before use.

</Callout>
