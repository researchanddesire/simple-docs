import { DeviceFlasher } from "@repo/device-tools/device-flasher";

Use this tool to install or recover OSSM firmware directly from a desktop browser over USB.

<Callout type="warn" title="Flash only when instructed by support">

Use Chrome or Edge, a data-capable USB cable, and stable power. Stop the OSSM and disconnect its motor power before connecting USB.

</Callout>

Flashing replaces the installed firmware and may require Wi-Fi or device settings to be entered again. Read [Flash or recover OSSM firmware](/ossm/tools) for preparation, success checks, and failure recovery before continuing.
