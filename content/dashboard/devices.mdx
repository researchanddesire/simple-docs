description: "Each device belongs to one Dashboard account. How to find your device's code, unpair before you sell, and what to do when a device says it's already paired."

Each Lockbox, Deepthroat Trainer and OSSM can be paired to **one** Dashboard account at a time. That account owns the device. A partner who controls your device doesn't pair it: they connect to your account instead.

The RADR wireless remote isn't paired to a Dashboard account.

## Pair a device

1. Sign in and open **My Devices**.
2. Under **Pairing & tutorials**, choose your device and follow the steps.

For device-specific steps, see [Pair your Lockbox](/lockbox/quick-start/pairing), [Pair your Trainer](/dtt/quick-start/pairing/pairing-guide) or [How to use your OSSM](/ossm/how-to-use).

For a Lockbox, use the pairing code from the box. Bluetooth pairing for the Lockbox is turned off in the Dashboard for now.

## Find your device's code

| Device | Where to find it | Does it change? |
| --- | --- | --- |
| **Lockbox** | On the Lockbox, open **Settings → Pairing**. The code shows as "Pairing: " followed by 6 characters. | Yes, every time the Lockbox restarts. Always use the code on screen now. |
| **Deepthroat Trainer** | The **Trainer ID** on the Trainer's screen. | No. |
| **OSSM** | In the OSSM menu, choose **Pairing**. The **Pair OSSM** screen shows the code. | Yes, often. If a code is rejected, leave **Pairing** and open it again for a fresh code, then type it straight away. |

## Unpair a device

1. Open **My Devices**.
2. Under **Paired devices**, find the device and select **Unpair**.

The device is unpaired straight away. There is no confirmation step.

What happens next:

- **Lockbox:** if it's online, it restarts and asks to be paired again. If it's offline, it asks the next time it starts up with Wi-Fi.
- **OSSM:** it notices the next time it restarts.

<Callout type="warning" title="End any lock session before you unpair a Lockbox">

Unpairing restarts the Lockbox. Make sure no lock session is running on it, and that the box is open, before you unpair it.

</Callout>

## Sell or give away a device

1. End any session that's running on the device.
2. [Unpair it](#unpair-a-device) from your account.
3. Tell the new owner to pair it to their own account.

If you can't sign in to the account that owns the device, email [support@researchanddesire.com](mailto:support@researchanddesire.com) with the device's code and your order confirmation.

If you plan to [delete your Dashboard account](/dashboard/delete-account), unpair your devices first. Deleting an account doesn't unpair them.

## Bought a second-hand device?

If pairing shows "Device already paired, please contact support if you believe this is an error.", the device still belongs to someone else's account.

1. Ask the person you bought it from to [unpair it](#unpair-a-device). Then pair it to your account.
2. If they can't, email [support@researchanddesire.com](mailto:support@researchanddesire.com) with the device's code and your proof of purchase.

<Callout type="warn" title="Draft — needs AJ decision">

Our device ownership transfer policy is not published anywhere today (DR-024). This is current support practice, written as policy. Approve, edit or remove it:

- We never tell anyone which account owns a device.
- If you can show you bought the device (an order confirmation, or a receipt from Etsy or an authorised reseller), and the previous owner can't or won't unpair it, we email the original buyer at the address on their order.
- If they agree, or don't reply within **30 days**, we move the device to your account. If they object, we don't.
- If you're the original buyer and just lost access to your old account, we unpair the device once your proof matches our records, usually the same day.

</Callout>

## Fix pairing messages

| You see | What it means | What to do |
| --- | --- | --- |
| "Device not found, please contact support if you believe this is an error." | The code doesn't match a device. A Lockbox code changes at every restart, and an OSSM code changes often. | Read the code on the device again and type it exactly. On an OSSM, open **Pairing** again for a fresh code. |
| "Must be alphanumeric, ex: ABC12" | The code has spaces, dashes, colons or other symbols. | Type only the letters and numbers. |
| "Device already paired, please contact support if you believe this is an error." | Another account owns the device. | See [Bought a second-hand device?](#bought-a-second-hand-device). |
| "Device is no longer available to pair" | Someone paired it a moment ago. | Check whether you already paired it, then contact support. |
| "Your partner doesn't have a…" | You're viewing your partner's account. | Switch back to **Your Account** in the account switcher to pair your own device. In the newer menu, pick one of your own devices in the device switcher. |
