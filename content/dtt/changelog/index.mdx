No dated, versioned DTT firmware release entries are available in this user-guide repository. The previous page mixed undated implementation notes, placeholder accordions, and a promotional image; those were not reliable release notes and have been removed from the published content.

## What a release entry must include

Future entries should be published newest first with:

- firmware version and release date;
- release channel and eligible hardware;
- user-visible changes;
- dashboard or API dependencies;
- known issues;
- update and recovery instructions;
- rollback or support boundary;
- source or artifact used to verify the entry.

## Find current status

Use [Firmware updates and recovery](/dtt/technical/firmware-updates) for the dynamic update behavior. The version assigned to a device can vary by release track, eligibility, and staged rollout; this page does not invent a “current” version.
