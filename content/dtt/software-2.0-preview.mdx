<Callout type="warn" title="Historical preview, not current setup guidance">

This undated preview described planned and staged behavior. Its enrollment promises, prospective features, limits, and channel availability are not treated as current facts. Use the dashboard controls offered to your account and [Firmware updates](/dtt/technical/firmware-updates).

</Callout>

## Behavior verified in current dashboard/API source

- The v2 settings API supplies templates as ordered segments and expands configured repeats.
- The v2 calibration API stores per-toy calibration for the session owner.
- The v2 completion API accepts Repetition, Endurance, Freeform, and Bounce results.
- The completion API accepts pass/fail data and contains three-strike processing.
- The dashboard exposes device-avatar selection for eligible accounts and firmware-channel controls for eligible devices.
- The server resolves firmware dynamically instead of publishing one hard-coded version here.

These server capabilities do not prove that every firmware version or account receives the same UI.

## Claims that remain unverified here

The checked-out repository does not contain the DTT firmware. Exact offline queue behavior, local capacity, retry timing, frame rate, per-version screens, current rollout percentages, and a guaranteed rollback path cannot be verified. See [Offline mode](/dtt/technical/offline-mode) for the conservative persistence boundary.
