The Trainer has one front button. The screen determines what a press does, so read the prompt before acting.

## Press types

| Press       | Meaning                                                  |
| ----------- | -------------------------------------------------------- |
| Short press | press and release                                        |
| Hold        | keep the button pressed until the screen acknowledges it |

The user-facing source does not define an exact hold duration for every firmware version.

## Action by state

| State                   | Short press                                      | Hold                                                          |
| ----------------------- | ------------------------------------------------ | ------------------------------------------------------------- |
| Welcome                 | begin startup/preflight                          | open local Wi-Fi setup                                        |
| Pairing prompt          | continue without pairing when offered            | follow the displayed prompt                                   |
| Calibration minimum     | capture the current closest comfortable position | no documented action                                          |
| Calibration maximum     | capture the current resting position             | no documented action                                          |
| Session or toy summary  | continue                                         | a skip action may exist on some firmware; use the screen text |
| Active segment          | no general stop command is documented            | developer-only skip may exist; do not rely on it for safety   |
| Grade or failed attempt | continue or retry as shown                       | no documented action                                          |
| Completion              | begin the next available flow as shown           | no documented action                                          |
| Wi-Fi portal            | may exit or restart on some firmware             | use the displayed prompt                                      |

<Callout type="warn" title="The front button is not an emergency stop">

To stop a physical session, stop your movement and move away from the toy. Switch the device off only when it is safe to reach the power switch. See [Safety and stopping](/dtt/safety).

</Callout>

## “Launch settings page”

This device prompt opens the Wi-Fi configuration portal. Templates, toys, partner access, and account preferences remain in the dashboard.

## If a press does nothing

1. Read the full screen; some states wait for an automatic check.
2. Release the button fully and try one deliberate short press.
3. If the device remains unresponsive, move away from the toy and power-cycle it.
4. Note the exact screen and report repeated freezes to support.
