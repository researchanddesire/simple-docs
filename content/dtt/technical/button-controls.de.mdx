Der Trainer verfügt über einen Knopf vorne. Der Bildschirm bestimmt, was ein Tastendruck bewirkt. Lesen Sie daher die Eingabeaufforderung, bevor Sie handeln.

## Drücken Sie Typen

| Drücken Sie | Bedeutung |
| ----------- | -------------------------------------------------------- |
| Kurz drücken | Pressemitteilung |
| Halten Sie | Halten Sie die Taste gedrückt, bis der Bildschirm dies bestätigt |

Die benutzerseitige Quelle definiert nicht für jede Firmware-Version eine genaue Haltedauer.

## Aktion nach Staat

| Staat | Kurz drücken | Halten Sie |
| --------- | ------------------------------------------------ | ------------------------------------------------------------- |
| Willkommen | Startup starten/preflight | Öffnen Sie das lokale Wi-Fi-Setup |
| Pairing-Eingabeaufforderung | ohne Kopplung fortfahren, wenn angeboten | Folgen Sie der angezeigten Aufforderung |
| Kalibrierungsminimum | Erfassen Sie die aktuell nächstgelegene bequeme Position | keine dokumentierte Maßnahme |
| Kalibrierungsmaximum | Erfassen der aktuellen Ruheposition | keine dokumentierte Maßnahme |
| Sitzungs- oder Spielzeugzusammenfassung | weiter | Bei manchen Firmwares gibt es möglicherweise eine Aktion zum Überspringen. Verwenden Sie den Bildschirmtext |
| Aktives Segment | es ist kein allgemeiner Stoppbefehl dokumentiert | Möglicherweise existiert ein nur für Entwickler vorgesehenes Überspringen. Verlassen Sie sich aus Sicherheitsgründen nicht darauf |
| Note oder Fehlversuch | Fahren Sie fort oder versuchen Sie es erneut, wie gezeigt | keine dokumentierte Maßnahme |
| Fertigstellung | Beginnen Sie den nächsten verfügbaren Fluss wie gezeigt | keine dokumentierte Maßnahme |
| Wi-Fi Portal | kann bei manchen Firmware-Versionen beendet oder neu gestartet werden | Verwenden Sie die angezeigte Eingabeaufforderung |

<Callout type="warn" title="Der vordere Knopf ist kein Not-Aus">

Um eine körperliche Sitzung zu beenden, stoppen Sie Ihre Bewegung und entfernen Sie sich vom Spielzeug. Schalten Sie das Gerät erst dann aus, wenn der Netzschalter sicher erreichbar ist. Siehe [Safety and stopping](/dtt/safety).

</Callout>

## „Einstellungsseite starten“

Diese Geräteaufforderung öffnet das Konfigurationsportal Wi-Fi. Vorlagen, Spielzeuge, Partnerzugriff und Kontoeinstellungen bleiben im Dashboard.

## Wenn ein Druck nichts bewirkt

1. Lesen Sie den gesamten Bildschirm; Einige Staaten warten auf eine automatische Prüfung.
2. Lassen Sie die Taste vollständig los und versuchen Sie es mit einem bewussten kurzen Druck.
3. Wenn das Gerät weiterhin nicht reagiert, entfernen Sie sich vom Spielzeug und schalten Sie es aus und wieder ein.
4. Notieren Sie sich den genauen Bildschirm und melden Sie wiederholte Einfrierungen dem Support.
