title: "Offline Mode and Result Persistence"
description: "Use cached Deep Throat Trainer settings conservatively and understand what the current source can and cannot verify about results."
---

## Evidence boundary

Device documentation and messages indicate that some firmware can run previously downloaded settings and show on-device feedback without a current server connection. The dashboard source confirms that settings are normally fetched online and results are persisted when the v2 completion endpoint receives a valid request from a paired Trainer.

The DTT firmware repository is not present in this checkout. This documentation therefore cannot verify a durable result queue, queue capacity, retention time, retry schedule, power-loss behavior, or the firmware versions that implement any of those details.

## Capability matrix

| Capability                          | Offline status                                                                      |
| ----------------------------------- | ----------------------------------------------------------------------------------- |
| Run previously downloaded settings  | supported by existing device guidance; verify on your firmware before relying on it |
| Position and on-device feedback     | available during a successfully started cached session                              |
| Download a new or edited template   | requires connectivity                                                               |
| Confirm cloud calibration save      | requires an accepted server request                                                 |
| Confirm dashboard result and points | not confirmed until the result appears online                                       |
| Check or download firmware          | requires connectivity                                                               |

## Prepare

1. Connect online and pair the Trainer.
2. Activate the intended template and toy.
3. Let the Trainer fetch and display their summaries.
4. Complete calibration if prompted.
5. Disconnect from the network and run a controlled, nonessential test.
6. Confirm the same template and toy appear before starting.

<Callout type="warn" title="Treat offline results as unsaved">

If a session record matters for progress, points, partner accountability, or any other consequence, train online and verify the record afterward. Do not promise that reconnection will recover an offline result.

</Callout>

## Reconnect

Reconnect Wi-Fi, restart normally, and let preflight finish. Check the dashboard. If an offline session appears, it was delivered; if it does not, there is no documented manual upload action in this repository.

## Wrong cached session

Return online, select the correct active template and toy, let the Trainer fetch them, and verify the summaries before disconnecting again.
