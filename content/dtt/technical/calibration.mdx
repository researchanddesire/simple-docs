Calibration maps the installed toy and mounting geometry to sensor positions. It is measurement, not a challenge to reach a maximum depth.

## First calibration

### 1. Verify the setup

Confirm the mount is stable, the installed toy matches the dashboard assignment, the sensor path is clear, and you can move away immediately.

### 2. Capture the closest comfortable position

Move slowly to the closest position you can comfortably control, hold still, and press the button when prompted.

### 3. Capture the resting position

Move back to the natural start/rest position, hold still, and press the button.

### 4. Confirm acceptance

<Callout type="success" title="Success">

The device accepts both values and advances to the session summary or first segment without a calibration error.

</Callout>

## Valid range enforced by the current API

The dashboard API clamps stored toy calibration to 1.5–21.5 cm and requires at least 2 cm between the stored minimum and maximum. These are software validation bounds, not medical recommendations or goals.

## Saved per-toy calibration

The current v2 API stores `minCm`, `maxCm`, and a calibration timestamp on the toy assigned to the session and owned by that account. A different toy, owner, assignment, or firmware flow may prompt again.

## Reset and recalibrate

1. Open the paired Trainer’s **Toybox** in the dashboard.
2. Select the exact toy.
3. Choose the reset/recalibrate action if shown.
4. Start a new online session with that toy.
5. Capture both positions again.

## Recovery

| Symptom                         | Action                                                                  |
| ------------------------------- | ----------------------------------------------------------------------- |
| positions are too close         | use a clearly separated but still comfortable rest and closest position |
| value changes while holding     | steady the mount and body; clear the sensor path                        |
| wrong toy is named              | stop, correct the dashboard toy assignment, and restart                 |
| saved calibration does not load | connect online, confirm account and toy, then recalibrate               |
| server rejects the save         | keep the session stopped, check connectivity, and retry once online     |

Do not publish or reuse “typical” depth values from another person. Continue to [Run your first session](/dtt/quick-start/first-session).
