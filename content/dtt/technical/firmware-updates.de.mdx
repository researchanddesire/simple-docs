## Automatische Prüfungen

Wenn ein Online-Trainer den aktuellen Update-Dienst aufruft, vergleicht der Server seine gemeldete Version mit der seinem Release-Track zugewiesenen Version. Berechtigung und gestaffelte Rollout-Logik können sich auf die zurückgegebene Firmware auswirken. Eine einzelne „neueste Version“ ist in diesem Handbuch daher nicht fest codiert.

## Vor einem Update

- Beenden und beenden Sie jede physische Sitzung.
- Platzieren Sie den Trainer sicher und ohne Spielzeug.
- Verwenden Sie eine stabile 2,4-GHz-Verbindung.
- Sorgen Sie für eine ausreichende Batterieladung; Das Repository definiert keinen erforderlichen Prozentsatz.
- Beginnen Sie nicht, wenn ein Strom- oder Verbindungsausfall wahrscheinlich ist.

## Während und nachher

Verfolgen Sie den Fortschrittsbildschirm des Geräts und lassen Sie es eingeschaltet. Lassen Sie den Preflight nach dem Neustart abschließen und überprüfen Sie, ob die erwartete Sitzung abgerufen werden kann.

<Callout type="success" title="Überprüfung">

Der Trainer startet normal neu, schließt seine Online-Prüfung ab und wiederholt das Update nicht und zeigt auch keinen Wiederherstellungsfehler an.

</Callout>

## Kanäle freigeben

Dashboard-Geräteeinstellungen können Firmware-Kanalsteuerungen für berechtigte Geräte verfügbar machen. Kanalnamen und Berechtigung können sich ändern. Wählen Sie nur einen Kanal aus, der derzeit für Ihr Konto angeboten wird, und verwenden Sie „Produktion“, wenn Sie keine Vorabversionssoftware testen möchten.

## Wenn ein Update fehlschlägt

1. Zeichnen Sie den Bildschirm und jede angezeigte Version auf.
2. Benutzen Sie den Trainer nicht.
3. Stellen Sie ein stabiles Netzwerk wieder her und starten Sie es einmal neu.
4. Wenn der normale Start nicht wiederhergestellt werden kann, verwenden Sie den [DTT Web Flasher](/dtt/tools/web-flasher) nur mit unterstützter Hardware, Browser und einem datenfähigen Kabel.
5. Wenden Sie sich an den Support, bevor Sie das Gerät löschen oder fehlgeschlagene Blitze wiederholen.

## Versions- und Rollback-Limits

Das aktuelle Benutzerhandbuch-Repository veröffentlicht keine aktuelle Firmware-Version, keine vollständige Versionshistorie, keine Support-Matrix und keinen garantierten Rollback-Pfad. Der Update-Dienst löst Versionen dynamisch auf. Melden Sie die von Ihrem Gerät oder Flasher angezeigte Version, wenn Sie Support anfordern.
