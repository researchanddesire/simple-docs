Le Trainer a un bouton sur le devant. L'écran détermine ce que fait une presse, alors lisez l'invite avant d'agir.

## Types de presse

| Presse | Signification |
| ----------- | -------------------------------------------------------- |
| Appui court | presse et communiqué |
| Tenir | maintenez le bouton enfoncé jusqu'à ce que l'écran le reconnaisse |

La source destinée à l'utilisateur ne définit pas de durée de conservation exacte pour chaque version du micrologiciel.

## Action par état

| État | Appui court | Tenir |
| ----------------------- | ------------------------------------------------ | ------------------------------------------------------------- |
| Bienvenue | commencer le démarrage/preflight | ouvrir la configuration locale Wi-Fi |
| Invite de couplage | continuer sans appairage lorsqu'il est proposé | suivez l'invite affichée |
| Minimum d'étalonnage | capturer la position confortable la plus proche actuelle | aucune action documentée |
| Calibrage maximum | capturer la position de repos actuelle | aucune action documentée |
| Résumé de la séance ou du jouet | continuer | une action de saut peut exister sur certains micrologiciels ; utiliser le texte à l'écran |
| Segment actif | aucune commande d'arrêt générale n'est documentée | Un saut réservé aux développeurs peut exister ; ne comptez pas sur lui pour votre sécurité |
| Note ou tentative ratée | continuez ou réessayez comme indiqué | aucune action documentée |
| Achèvement | commencez le prochain flux disponible comme indiqué | aucune action documentée |
| Portail Wi-Fi | peut quitter ou redémarrer sur certains firmware | utilisez l'invite affichée |

<Callout type="warn" title="Le bouton avant n'est pas un arrêt d'urgence">

Pour arrêter une séance physique, arrêtez votre mouvement et éloignez-vous du jouet. Éteignez l'appareil uniquement lorsqu'il est possible d'atteindre l'interrupteur d'alimentation en toute sécurité. Voir [Safety and stopping](/dtt/safety).

</Callout>

## "Lancer la page des paramètres"

Cette invite de périphérique ouvre le portail de configuration Wi-Fi. Les modèles, les jouets, l'accès des partenaires et les préférences du compte restent dans le tableau de bord.

## Si une presse ne fait rien

1. Lisez le plein écran ; certains États attendent un contrôle automatique.
2. Relâchez complètement le bouton et essayez d'appuyer brièvement et délibérément.
3. Si l'appareil ne répond toujours pas, éloignez-vous du jouet et redémarrez-le.
4. Notez l'écran exact et signalez les blocages répétés au support.
