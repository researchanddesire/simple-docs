---
title: "LED and Screen Feedback"
description: "Interpret Deep Throat Trainer position feedback using color, text, and movement together."
---

The LED strip provides quick position feedback, but color must never be the only source of meaning. Use the screen text, target indicator, and your controlled movement together.

## During a segment

| Visual state            | Meaning in current user guidance                           | Response                                                      |
| ----------------------- | ---------------------------------------------------------- | ------------------------------------------------------------- |
| Green / in target       | measured position is within the target window              | maintain only while comfortable                               |
| Yellow / ahead          | measured position is shallower or ahead of the target      | use the screen direction; adjust gradually                    |
| Red / behind or outside | measured position is deeper, behind, or outside the target | use the screen direction; stop rather than force a correction |

Firmware and mode can alter presentation. The accompanying text and position indicator are authoritative when a color appears inconsistent.

## Non-training states

Idle, completion, grade, and failure screens may also use color. Always pair the color with the visible label such as **complete**, **grade**, **failed**, or an error code.

## If color is difficult to distinguish

- Use the on-screen position/target display.
- Reduce environmental glare.
- Choose a pace slow enough to read the display.
- Do not ask another person to direct deeper or faster movement based on color alone.

## Unexpected feedback

| Symptom                      | Check                                                                             |
| ---------------------------- | --------------------------------------------------------------------------------- |
| feedback does not change     | sensor path, mount stability, toy assignment, and calibration                     |
| feedback seems reversed      | screen direction and current mode; stop and recalibrate if uncertain              |
| colors flicker at a boundary | slow down and widen or lower the template target if available                     |
| no LED but screen works      | continue only if screen feedback is sufficient; report repeated hardware behavior |

See [Device states](/dtt/technical/device-states) for the full sequence.
