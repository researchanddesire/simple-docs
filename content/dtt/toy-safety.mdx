# Before using a toy

Use a toy made from a smooth, non-porous material and inspect it for damage. Clean it according to its manufacturer's instructions.

Install the toy firmly in the trainer and pull gently to confirm it is secure. Recheck the backboard and suction cups at the same time.

# Set the toy in the Dashboard

1. Open **Deepthroat Trainer → Toybox** in the [R+D Dashboard](https://dashboard.researchanddesire.com/).
2. Choose the R+D toy you are using, or add the requested measurements for a custom toy.
3. Set it as the current toy before training.

Update the Toybox whenever you switch toys. The trainer uses this information for the session.

Start with a short, simple session. Stop immediately for pain, breathing difficulty, numbness, dizziness, or unexpected movement.
