# What you need

- A smooth, non-porous mounting surface such as glass, acrylic, or glazed tile.
- The backboard and suction cups.
- A compatible toy.
- A charged trainer, an R+D account, and 2.4 GHz Wi-Fi.

# Set up the trainer

1. Clean and dry the mounting surface. Lightly moisten the suction cups.
2. Secure the backboard with all suction cups.
3. Attach the trainer to the backboard using the hook-and-loop mounting surface.
4. Install the toy and check that it is secure.
5. Power on the trainer and note the Trainer ID shown.
6. Sign in to the [R+D Dashboard](https://dashboard.researchanddesire.com/) and open **Settings → Devices**.
7. Enter the Trainer ID to pair it, then follow the Wi-Fi setup for a 2.4 GHz network.

Pairing is complete when the trainer appears under **Settings → Devices**. Wi-Fi is recommended so sessions and results can sync.

Unplug the charging cable before a training session. Recheck the mount by hand before every use.
