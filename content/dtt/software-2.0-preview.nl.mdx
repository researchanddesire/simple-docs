## Gedrag geverifieerd in huidige dashboard/API bron

- De v2-instellingen API levert sjablonen als geordende segmenten en breidt geconfigureerde herhalingen uit.
- De v2-kalibratie API slaat kalibratie per stuk speelgoed op voor de sessie-eigenaar.
- De v2-voltooiing API accepteert resultaten van Herhaling, Uithoudingsvermogen, Vrije vorm en Bounce.
- De voltooiing API accepteert pass/fail-gegevens en bevat three-strike-verwerking.
- Het dashboard toont apparaat-avatarselectie voor in aanmerking komende accounts en firmware-kanaalcontroles voor in aanmerking komende apparaten.
- De server lost de firmware dynamisch op in plaats van hier één hardgecodeerde versie te publiceren.

Deze servermogelijkheden bewijzen niet dat elke firmwareversie of account dezelfde gebruikersinterface krijgt.

## Claims die hier niet geverifieerd blijven

De uitgecheckte repository bevat niet de DTT-firmware. Exact offline wachtrijgedrag, lokale capaciteit, timing van nieuwe pogingen, framesnelheid, schermen per versie, huidige uitrolpercentages en een gegarandeerd terugdraaipad kunnen niet worden geverifieerd. Zie [Offline mode](/dtt/technical/offline-mode) voor de conservatieve persistentiegrens.
