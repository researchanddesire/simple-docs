## Comportement vérifié dans la source actuelle du tableau de bord/API

- Les paramètres v2 API fournissent des modèles sous forme de segments ordonnés et étendent les répétitions configurées.
- L'étalonnage v2 API stocke l'étalonnage par jouet pour le propriétaire de la session.
- La complétion v2 API accepte les résultats de répétition, d'endurance, de forme libre et de rebond.
- L'achèvement API accepte les données pass/fail et contient un traitement en trois temps.
- Le tableau de bord expose la sélection d'avatar d'appareil pour les comptes éligibles et les contrôles de canal de micrologiciel pour les appareils éligibles.
- Le serveur résout le micrologiciel de manière dynamique au lieu de publier ici une version codée en dur.

Ces capacités du serveur ne prouvent pas que chaque version du micrologiciel ou chaque compte reçoit la même interface utilisateur.

## Réclamations qui restent non vérifiées ici

Le référentiel extrait ne contient pas le micrologiciel DTT. Le comportement exact de la file d'attente hors ligne, la capacité locale, le délai de nouvelle tentative, la fréquence d'images, les écrans par version, les pourcentages de déploiement actuels et un chemin de restauration garanti ne peuvent pas être vérifiés. Voir [Offline mode](/dtt/technical/offline-mode) pour la limite de persistance conservatrice.
