## Vorflug

- Führen Sie erneut einen Zugtest an der Halterung durch.
- Vergewissern Sie sich, dass das Spielzeug sauber, unbeschädigt und sicher ist und mit der Armaturenbrettauswahl übereinstimmt.
- Trennen Sie das Ladekabel.
- Stellen Sie sicher, dass Sie sofort wegziehen können.
- Wählen Sie ein Segment mit den niedrigsten Einstellungen, die Sie bequem steuern können.

## Starten

1. Schalten Sie den Trainer ein.
2. Lassen Sie den Startvorgang und die Netzwerkprüfungen abschließen.
3. Überprüfen Sie die auf dem Gerät angezeigte Sitzung und das Spielzeug. Stoppen Sie, wenn eines davon unerwartet ist.
4. Schließen Sie die Kalibrierung ab, wenn Sie dazu aufgefordert werden.
5. Starten Sie das Segment und folgen Sie dem Bildschirm. Behandeln Sie Text- und Positionsindikatoren als primäres Feedback. Verlassen Sie sich nicht nur auf die Farbe.

## Stoppen oder beenden

Sie können jederzeit aufhören, indem Sie Ihre Bewegung beenden und sich vom Spielzeug entfernen. Schalten Sie das Gerät aus, sobald Sie den Schalter sicher erreichen können.

Wenn Sie das Segment beendet haben, fahren Sie fort, bis der Abschlussbildschirm angezeigt wird.

<Callout type="success" title="Erfolg">

Die Halterung blieb stabil, Sie hatten die Kontrolle, das Gerät zeigte einen Grad- oder Fertigstellungsstatus an und es blieb kein Fehler auf dem Bildschirm.

</Callout>

## Weiter

Öffnen Sie [Checking results](/dtt/quick-start/checking-results). Wenn die Sitzung fehlt, gehen Sie nicht davon aus, dass später ein Offline-Ergebnis hochgeladen wird. Befolgen Sie die evidenzbasierten Wiederherstellungsschritte auf dieser Seite.
