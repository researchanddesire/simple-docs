Vorlagen enthalten ein oder mehrere Trainingssegmente. Erstellen Sie zunächst eine private Vorlage, testen Sie sie mit komfortablen Einstellungen und geben Sie sie erst frei, wenn ihr Verhalten klar ist.

## Erstellen Sie eine Vorlage

1. Öffnen Sie Ihren gekoppelten Trainer im Dashboard.
2. Öffnen Sie **Vorlagen** und wählen Sie **Neu hinzufügen**.
3. Geben Sie einen aussagekräftigen Namen und wählen Sie das gewünschte Spielzeug aus.
4. Fügen Sie Segmente hinzu und überprüfen Sie die Parameter jedes Modus.
5. Speichern Sie es und bestätigen Sie dann explizit, welche Vorlage aktiv ist.

## Eigentümer- und Partnerzugriff

Partnerverbindungen gelten auf Kontoebene, nicht nur für ein Gerät. Verwalten Sie Einladungen und aktuellen Zugriff in [Partner settings](https://dashboard.researchanddesire.com/app/settings/partners).

Bevor eine andere Person eine Vorlage erstellt oder ändert, vereinbaren Sie zulässige Einstellungen, Stopperwartungen und die Art und Weise, wie der Zugriff widerrufen wird. Die Dashboard-Benutzeroberfläche ist die Autorität, für die das Konto derzeit kontrolliert wird.

## Öffentliches Teilen

Vorlagen sind privat, es sei denn, die öffentliche Freigabe ist aktiviert. Eine öffentliche Vorlage kann die Identität des Erstellers, den Titel, die Beschreibung, den Schwierigkeitsgrad, die Segmentstruktur und andere in der Ansicht „Erkunden“ angezeigte Felder offenlegen.

1. Entfernen Sie privaten oder identifizierenden Text.
2. Fügen Sie eine genaue Beschreibung des Zwecks und der Schwierigkeit hinzu.
3. Aktivieren Sie die öffentliche Freigabe erst, nachdem Sie die öffentliche Vorschau überprüft haben.
4. Deaktivieren Sie die Freigabe, wenn Sie keine Entdeckung mehr wünschen; importierte Kopien können auf anderen Konten verbleiben.

## Importieren

Öffnen Sie **Erkunden**, zeigen Sie eine Vorschau des Erstellers, der Spielzeugannahmen, des Modus und der Segmenteinstellungen an und wählen Sie dann **Vorlage verwenden** oder **Importieren**, sofern verfügbar. Beim Importieren wird eine Kopie erstellt, die Sie überprüfen können. Es macht ein unbekanntes Setup nicht sicher.

Die Abonnementberechtigung und die Beschränkungen für aktive Vorlagen können sich ändern. Verwenden Sie in diesem Handbuch die aktuelle Dashboard-Meldung und [Subscription settings](https://dashboard.researchanddesire.com/app/settings/subscription) als Autorität und nicht einen fest codierten Grenzwert.

## Vor dem Ausführen einer importierten Vorlage

- seine Spielzeugzuordnung an das installierte Spielzeug anpassen;
- Verringern Sie alle Einstellungen, die Sie nicht bequem steuern können.
- Kalibrieren, wenn Sie dazu aufgefordert werden;
- Verwenden Sie ein Segment für den ersten Test.
- Halten Sie den Weg vom Spielzeug frei.

## Fehlerbehebung

| Problem | Prüfen |
| ------------ | --------------------------------------------------------------------------------------------------- |
| Importaktion nicht verfügbar | aktuelle Abonnementberechtigung und ob Sie das beabsichtigte Konto kontrollieren |
| Änderungen sind deaktiviert | Status „Partnerkontrolle“ oder „Kontrolle aufgeben“ in den Dashboard-Einstellungen |
| falsche Sitzungsdownloads | welche Vorlage aktiv ist und ob der Trainer einen Online-Abruf durchgeführt hat |
| öffentliche Vorlage nicht sichtbar | Status der öffentlichen Freigabe und ob Moderations- oder Entfernungsinformationen angezeigt werden |
