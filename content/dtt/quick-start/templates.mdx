title: "Create, Share, and Import Templates"
description: "Manage Deep Throat Trainer templates, toy assignments, partner access, public sharing, and active-template behavior."
---

Templates contain one or more training segments. Build a private template first, test it at comfortable settings, and share only after its behavior is clear.

## Create a template

1. Open your paired Trainer in the dashboard.
2. Open **Templates** and choose **Add new**.
3. Give it a descriptive name and select the intended toy.
4. Add segments and review each mode’s parameters.
5. Save it, then explicitly confirm which template is active.

## Owner and partner access

Partner connections apply at the account level, not to only one device. Manage invitations and current access in [Partner settings](https://dashboard.researchanddesire.com/app/settings/partners).

Before another person creates or changes a template, agree on allowed settings, stopping expectations, and how access will be revoked. The dashboard UI is the authority for which account is currently being controlled.

## Public sharing

Templates are private unless public sharing is enabled. A public template can expose its creator identity, title, description, difficulty, segment structure, and other fields shown in the Explore view.

1. Remove private or identifying text.
2. Add an accurate purpose and difficulty description.
3. Enable public sharing only after reviewing the public preview.
4. Disable sharing when you no longer want discovery; imported copies may remain in other accounts.

## Import

Open **Explore**, preview the creator, toy assumptions, mode, and segment settings, then choose **Use Template** or **Import** when available. Importing creates a copy you can review; it does not make an unknown setup safe.

Subscription eligibility and active-template limits can change. Use the current dashboard message and [Subscription settings](https://dashboard.researchanddesire.com/app/settings/subscription) as the authority rather than a hard-coded limit in this guide.

## Before running an imported template

- match its toy assignment to the installed toy;
- lower any setting you cannot comfortably control;
- calibrate when prompted;
- use one segment for the first test;
- keep the route away from the toy unobstructed.

## Troubleshooting

| Problem                     | Check                                                                                 |
| --------------------------- | ------------------------------------------------------------------------------------- |
| import action unavailable   | current subscription eligibility and whether you are controlling the intended account |
| edits are disabled          | partner control or Give Up Control state in dashboard settings                        |
| wrong session downloads     | which template is active and whether the Trainer completed an online fetch            |
| public template not visible | public-sharing state and whether moderation or removal information is shown           |

Continue to [Training modes](/dtt/training-modes).
