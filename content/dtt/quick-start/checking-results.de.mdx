## Finden Sie die Sitzung

1. Melden Sie sich unter [dashboard.researchanddesire.com](https://dashboard.researchanddesire.com) an.
2. Öffnen Sie Ihr Deep Throat Trainer.
3. Öffnen Sie die Aktivitäts- oder aktuelle Sitzungsansicht.
4. Wählen Sie die abgeschlossene Sitzung aus, um die Segmentergebnisse zu überprüfen.

<Callout type="success" title="Erfolg">

Die Sitzung hat eine Abschlusszeit und ein oder mehrere Segmentergebnisse. Punkte und Ranglistenposition können aktualisiert werden, nachdem der Server das Ergebnis akzeptiert hat.

</Callout>

## Bestenlisten und Punkte

Das Dashboard vergibt Punkte aus den vom Server akzeptierten Sitzungsdaten. Die genaue Berechnung hängt vom Trainingsmodus und der aktiven Produktlogik ab; Vergleichen Sie Rohwerte aus verschiedenen Modi nicht so, als ob es sich um dieselbe Messung handeln würde.

- Öffnen Sie [Leaderboards](https://dashboard.researchanddesire.com/app/leaderboards), um die aktuelle Wettbewerbsansicht anzuzeigen.
- Überprüfen Sie jeden [training mode](/dtt/training-modes) auf die Messungen, die dieser Modus hervorhebt.
- E-Mail-Support, wenn eine abgeschlossene Online-Sitzung ein Ergebnis hat, die angezeigten Punkte jedoch nicht aktualisiert werden.

## E-Mail-Benachrichtigungen

Die Rangliste und andere E-Mail-Kategorien finden Sie unter [Advanced settings](https://dashboard.researchanddesire.com/app/settings/advanced). Die aktuelle Anwendungsquelle stellt keine Opt-out-Funktion für die öffentliche Bestenliste offen, sodass in diesem Leitfaden nicht behauptet wird, dass eine solche Einstellung existiert.

## Wenn die Sitzung fehlt

1. Bestätigen Sie, dass der Trainer mit dem richtigen Konto gekoppelt wurde.
2. Bestätigen Sie, dass vor der Sitzung ein Online-Gesundheitscheck durchgeführt wurde.
3. Aktualisieren Sie die Aktivitätsansicht einmal.
4. Wenn die Sitzung offline war, betrachten Sie den Upload als **nicht garantiert**. Der Server zeichnet nur dann ein v2-Ergebnis auf, wenn er die Abschlussanforderung erhält. Das ausgecheckte Repository enthält nicht die DTT-Firmware, die zum Überprüfen einer dauerhaften Offline-Warteschlange, eines Aufbewahrungslimits oder eines Wiederholungsplans erforderlich ist.
5. Wenn das Ergebnis immer noch nicht angezeigt wird, führen Sie eine kurze Online-Testsitzung durch. Kontaktieren Sie den Support mit dem Trainer ID, der ungefähren Fertigstellungszeit, dem Modus und der genauen Gerätemeldung.

<Callout type="warn" title="Verlassen Sie sich für Aufzeichnungen oder Verantwortlichkeit nicht auf eine Offline-Sitzung">

Das Feedback auf dem Gerät funktioniert möglicherweise über zwischengespeicherte Einstellungen, die Dashboard-Persistenz wird jedoch nicht bestätigt, bis die Sitzung online erscheint.

</Callout>
