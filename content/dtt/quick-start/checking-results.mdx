## Find the session

1. Sign in at [dashboard.researchanddesire.com](https://dashboard.researchanddesire.com).
2. Open your Deep Throat Trainer.
3. Open its activity or recent-session view.
4. Select the completed session to review segment results.

<Callout type="success" title="Success">

The session has a completion time and one or more segment results. Points and leaderboard position may update after the server accepts the result.

</Callout>

## Leaderboards and points

The dashboard awards points from session data accepted by the server. The exact calculation depends on the training mode and active product logic; do not compare raw grades from different modes as if they were the same measurement.

- Open [Leaderboards](https://dashboard.researchanddesire.com/app/leaderboards) to see the current competition view.
- Review each [training mode](/dtt/training-modes) for the measurements that mode emphasizes.
- Email support if a completed online session has a result but the displayed points do not update.

## Email notifications

Leaderboard and other email categories are under [Advanced settings](https://dashboard.researchanddesire.com/app/settings/advanced). The current application source does not expose a public-leaderboard opt-out, so this guide does not claim that such a setting exists.

## If the session is missing

1. Confirm the Trainer was paired to the correct account.
2. Confirm it completed an online health check before the session.
3. Refresh the activity view once.
4. If the session was offline, treat the upload as **not guaranteed**. The server records a v2 result only when it receives the completion request; the checked-out repository does not contain the DTT firmware needed to verify a durable offline queue, retention limit, or retry schedule.
5. If the result still does not appear, run a short online test session. Contact support with the Trainer ID, approximate completion time, mode, and exact device message.

<Callout type="warn" title="Do not rely on an offline session for records or accountability">

On-device feedback may work from cached settings, but dashboard persistence is unconfirmed until the session appears online.

</Callout>
