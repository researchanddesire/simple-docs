## Before you begin

- Charge the Trainer.
- Create or sign in to a [dashboard account](https://dashboard.researchanddesire.com/?register=true).
- Keep the device nearby so you can restart it and read the display.

## Pairing steps

### 1. Find the Trainer ID

Switch the Trainer on. During startup, read the 5–6 character Trainer ID at the top of the display. Copy its letters and numbers exactly.

![Deep Throat Trainer display highlighting the Trainer ID at the top](../../img/IMG_5840.webp)

### 2. Open device settings

Open [dashboard device settings](https://dashboard.researchanddesire.com/app/settings). If you are signed out, the dashboard preserves this destination through sign-in.

### 3. Enter the ID

Choose the Deep Throat Trainer pairing action, enter the ID without spaces, and submit it.

### 4. Verify

<Callout type="success" title="Success">

The dashboard shows a success confirmation and the Trainer appears in your device list. Pairing does not configure Wi-Fi; complete [Wi-Fi setup](/dtt/quick-start/pairing/wifi-setup) next.

</Callout>

## Troubleshooting

| Problem                                     | Action                                                                                                                         |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| ID disappeared before you copied it         | switch off, switch on, and watch the boot screen                                                                               |
| ID rejected                                 | check case, letters versus numbers, and accidental spaces                                                                      |
| device is already paired                    | ask the current owner to unpair it in dashboard device settings                                                                |
| original account or owner is unavailable    | email [support@researchanddesire.com](https://www.researchanddesire.com/pages/contact-us) with the Trainer ID and available purchase details |
| dashboard says paired but device is offline | use [Wi-Fi setup](/dtt/quick-start/pairing/wifi-setup); do not pair again                                                      |
