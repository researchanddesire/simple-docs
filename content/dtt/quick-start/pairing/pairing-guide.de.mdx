## Bevor Sie beginnen

- Laden Sie den Trainer auf.
- Erstellen Sie ein [dashboard account](https://dashboard.researchanddesire.com/?register=true) oder melden Sie sich an.
- Halten Sie das Gerät in der Nähe, damit Sie es neu starten und die Anzeige ablesen können.

## Pairing-Schritte

### 1. Finden Sie Trainer ID

Schalten Sie den Trainer ein. Lesen Sie während des Startvorgangs die 5–6 Zeichen Trainer ID oben auf dem Display ab. Kopieren Sie die Buchstaben und Zahlen genau.

![Deep Throat Trainer display highlighting the Trainer ID at the top](../../img/IMG_5840.webp)

### 2. Geräteeinstellungen öffnen

Öffnen Sie [dashboard device settings](https://dashboard.researchanddesire.com/app/settings). Wenn Sie abgemeldet sind, behält das Dashboard dieses Ziel bis zur Anmeldung bei.

### 3. Geben Sie die ID ein

Wählen Sie die Kopplungsaktion Deep Throat Trainer, geben Sie die ID ohne Leerzeichen ein und senden Sie sie ab.

### 4. Überprüfen

<Callout type="success" title="Erfolg">

Das Dashboard zeigt eine Erfolgsbestätigung an und der Trainer erscheint in Ihrer Geräteliste. Beim Pairing wird Wi-Fi nicht konfiguriert. Vervollständigen Sie als nächstes [Wi-Fi setup](/dtt/quick-start/pairing/wifi-setup).

</Callout>

## Fehlerbehebung

| Problem | Aktion |
| ------------------------------------------- | --------------------------------------------------------------------- |
| ID ist verschwunden, bevor Sie sie kopiert haben | ausschalten, einschalten und den Startbildschirm ansehen |
| ID abgelehnt | Groß-/Kleinschreibung, Buchstaben versus Zahlen und zufällige Leerzeichen prüfen |
| Gerät ist bereits gekoppelt | Bitten Sie den aktuellen Besitzer, das Gerät in den Geräteeinstellungen im Dashboard zu entkoppeln |
| Das ursprüngliche Konto oder der ursprüngliche Eigentümer ist nicht verfügbar | Senden Sie eine E-Mail an [support@researchanddesire.com](mailto:support@researchanddesire.com) mit dem Trainer ID und den verfügbaren Kaufdetails |
| Dashboard zeigt „gekoppelt“ an, aber das Gerät ist offline | verwenden Sie [Wi-Fi setup](/dtt/quick-start/pairing/wifi-setup); nicht erneut koppeln |
