---
title: "Connect the Trainer to Wi-Fi"
description: "Configure a 2.4 GHz Wi-Fi network through the Trainer Setup portal and verify the connection."
---

Wi-Fi lets the Trainer fetch settings, send results, and check for updates. This task is separate from account pairing.

## Requirements

- A 2.4 GHz Wi-Fi network and its password
- A phone, tablet, or computer with Wi-Fi
- The powered Trainer close to the router during setup

<Callout type="warn">

The documented Trainer setup supports 2.4 GHz Wi-Fi. A combined-band router may work when it allows 2.4 GHz clients, but if setup fails, use a separately named 2.4 GHz or IoT network. Do not disable network security merely to connect the device.

</Callout>

## Connect

### 1. Enter setup mode

From the welcome screen, hold the front button when the display offers to launch the settings page. On the device, “settings page” means Wi-Fi setup, not template settings.

### 2. Join Trainer Setup

On your phone or computer, join the temporary network named **Trainer Setup**. Its “no internet” warning is expected; choose to stay connected.

### 3. Open the portal

Wait for the captive portal. If it does not open, browse to `http://192.168.4.1` while still connected to **Trainer Setup**. Temporarily disabling mobile data can prevent the phone from bypassing the local network.

### 4. Choose the network

Select **Configure Wi-Fi**, choose the intended 2.4 GHz network, enter its password, and save.

### 5. Verify

The Trainer should connect and restart. Let startup complete.

<Callout type="success" title="Success">

The Trainer leaves the setup network, restarts, and completes its online check without E-DTT-1.

</Callout>

## If setup fails

| Symptom                                | Try                                                                                            |
| -------------------------------------- | ---------------------------------------------------------------------------------------------- |
| portal does not open                   | remain on Trainer Setup, open `192.168.4.1`, disable mobile data, or try another client device |
| home network does not appear           | confirm it broadcasts 2.4 GHz and move closer to the router                                    |
| restart returns to offline             | repeat setup and re-enter the password carefully                                               |
| connected to Wi-Fi but E-DTT-1 appears | follow [E-DTT-1 troubleshooting](/dtt/errors/e-dtt-1)                                          |
| corporate, hotel, or filtered network  | test a simple phone hotspot; networks requiring a browser login may not work                   |
