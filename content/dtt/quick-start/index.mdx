---

Complete these tasks in order. Each linked page includes a success check and recovery path.

| Step | Task                                                                        | You are ready when…                                        |
| ---: | --------------------------------------------------------------------------- | ---------------------------------------------------------- |
|    1 | [Read safety and stopping](/dtt/safety)                                     | you can move away immediately and the setup area is clear  |
|    2 | [Charge and mount](/dtt/quick-start/getting-started)                        | the backboard passes a pull test and the Trainer is secure |
|    3 | [Create an account](https://dashboard.researchanddesire.com/?register=true) | you can sign in to the dashboard                           |
|    4 | [Pair the Trainer](/dtt/quick-start/pairing/pairing-guide)                  | it appears in dashboard device settings                    |
|    5 | [Connect Wi-Fi](/dtt/quick-start/pairing/wifi-setup)                        | the Trainer restarts and completes its online check        |
|    6 | [Choose and assign a toy](/dtt/quick-start/using-toys)                      | the installed toy matches the dashboard selection          |
|    7 | [Calibrate](/dtt/technical/calibration)                                     | both positions are accepted without an error               |
|    8 | [Run one first segment](/dtt/quick-start/first-session)                     | the device reaches its completion screen                   |
|    9 | [Check the result](/dtt/quick-start/checking-results)                       | the session appears in the dashboard                       |

<Callout type="info" title="Allow time for setup">

The repository does not publish a reliable setup duration. Do not rush mounting, toy inspection, or calibration to meet an estimated time.

</Callout>
