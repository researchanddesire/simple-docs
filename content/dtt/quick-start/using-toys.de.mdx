Der Trainer verwendet bei der Interpretation der Position die Abmessungen und die Kalibrierung des ausgewählten Spielzeugs. Eine nicht übereinstimmende Auswahl an physischem Spielzeug und Dashboard kann dazu führen, dass das Feedback ungenau wird.

## Kompatibilitätscheckliste

Benutzen Sie ein Spielzeug nur, wenn alle diese Aussagen zutreffen:

- sein Hersteller gibt das Material und die Reinigungsmethode an;
- es ist sauber, intakt und frei von Rissen, Rissen, scharfen Kanten, Klebrigkeit oder anderen Beschädigungen;
- es kann ohne einen improvisierten losen Adapter sicher befestigt werden;
- seine Form lässt den Sensorweg des Trainers frei;
- Sie können es verwenden und entfernen, während Sie die Kontrolle über Ihre Bewegung behalten.

Das Repository veröffentlicht keine universellen Mindest- oder Höchstmaße für Spielzeug. Wenn der Sitz oder das Sensorspiel unsicher ist, wenden Sie keine Gewalt an. Kontaktieren Sie vor der Verwendung den Support.

## Schmiermittel und Reinigung

Beachten Sie die Schmiermittelkompatibilität des Spielzeugherstellers. Für R+D Silikonspielzeuge spezifiziert die bestehende Produktrichtlinie wasserbasiertes Gleitmittel. Gehen Sie nicht davon aus, dass ein Schmiermittel mit einem unbekannten Material kompatibel ist.

Reinigen und trocknen Sie das Spielzeug vor und nach dem Gebrauch vollständig. Tauchen Sie den Körper des Trainers nicht ein.

## Installieren Sie das Spielzeug

1. Schalten Sie den Trainer aus.
2. Überprüfen Sie den Befestigungspunkt und das Spielzeug.
3. Befestigen Sie das Spielzeug mit der dafür vorgesehenen Verbindung.
4. Führen Sie einen vorsichtigen Zugtest durch. Es darf sich nicht drehen, lockern oder lösen.
5. Stellen Sie sicher, dass der Sensor durch nichts blockiert wird.

## Weisen Sie es im Dashboard zu

1. Melden Sie sich an und öffnen Sie die **Spielzeugkiste** Ihres gekoppelten Trainers.
2. Wählen Sie das passende R+D-Spielzeug aus oder fügen Sie ein individuelles Spielzeug hinzu, dessen Maße Sie überprüfen können.
3. Legen Sie diesen Eintrag als Standard fest oder weisen Sie ihn der spezifischen Vorlage zu, die Sie verwenden möchten.
4. Vergewissern Sie sich vor dem Start, dass in der Gerätesitzung das erwartete Spielzeug angezeigt wird.

## Wenn Sie Spielzeug wechseln

Aktualisieren Sie die Dashboard-Zuweisung und führen Sie eine Neukalibrierung durch, wenn Sie dazu aufgefordert werden. Verwenden Sie die Kalibrierung nicht erneut, nur weil zwei Spielzeuge ähnlich aussehen.
