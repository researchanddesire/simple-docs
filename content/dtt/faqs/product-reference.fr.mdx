## Qu'est-ce que le Trainer ID ?

Il s'agit du court identifiant de couplage de compte affiché lors du démarrage. Il ne s'agit pas du mot de passe Wi-Fi ou d'un identifiant de modèle. Incluez-le dans les demandes d’assistance, mais ne le publiez pas inutilement.

## Où se trouvent les paramètres d'entraînement ?

Les modèles, les jouets, l'accès des partenaires, les abonnements et les paramètres de compte se trouvent dans le tableau de bord. Un message de l'appareil concernant le lancement de la « page des paramètres » fait référence à son portail Wi-Fi local.

## Quelle version du firmware ai-je ?

La source actuelle destinée à l'utilisateur n'expose pas un écran de version documenté de manière cohérente. Utilisez l'écran de mise à jour et les commandes du micrologiciel du tableau de bord disponibles sur votre appareil, et incluez toute version affichée dans une demande d'assistance.

## Les dimensions exactes et les spécifications électriques sont-elles publiées ?

Pas dans ce référentiel de guides d'utilisation. La page [Specifications](/dtt/specs) répertorie uniquement les faits vérifiés destinés à l'utilisateur et marque les valeurs manquantes plutôt que de les estimer.

## Existe-t-il un développeur API ?

Le référentiel du tableau de bord contient des API d'appareil, mais leur présence n'en fait pas une interface publique stable. Utilisez [Developer Docs](https://dev.researchanddesire.com) pour les intégrations prises en charge et les conseils d'authentification.

## Où puis-je signaler un problème ?

Utilisez le contrôle d'aide du tableau de bord ou envoyez un e-mail à [support@researchanddesire.com](mailto:support@researchanddesire.com). Incluez le Trainer ID, le message exact, la version du micrologiciel si elle est affichée, le type de réseau et les étapes de reproduction.
