## What is the Trainer ID?

It is the short account-pairing identifier shown during boot. It is not the Wi-Fi password or a template ID. Include it in support requests, but do not publish it unnecessarily.

## Where are training settings?

Templates, toys, partner access, subscriptions, and account settings are in the dashboard. A device message about launching the “settings page” refers to its local Wi-Fi portal.

## Which firmware version do I have?

The current user-facing source does not expose a consistently documented version screen. Use the update screen and dashboard firmware controls available to your device, and include any displayed version in a support request.

## Are exact dimensions and electrical specifications published?

Not in this user-guide repository. The [Specifications](/dtt/specs) page lists only verified user-facing facts and marks missing values rather than estimating them.

## Is there a developer API?

The dashboard repository contains device APIs, but their presence does not make them a stable public interface. Use [Developer Docs](https://dev.researchanddesire.com) for supported integrations and authentication guidance.

## Where do I report a problem?

Use the dashboard Help control or email [support@researchanddesire.com](mailto:support@researchanddesire.com). Include the Trainer ID, exact message, firmware version if shown, network type, and reproduction steps.
