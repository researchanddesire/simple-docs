Cette page répertorie uniquement les valeurs prises en charge par la source actuelle du produit et de l'application. Contactez l'assistance lorsqu'une valeur non publiée affecte l'installation, le déplacement, la réparation ou la compatibilité.

| Article | Informations vérifiées |
| ------------------- | ------------------------------------------------------------------------------------------------------------- |
| Couplage de compte | court Trainer ID affiché lors du démarrage |
| Configuration du réseau | 2,4 GHz Wi-Fi via le portail local **Trainer Setup** |
| Adresse de configuration locale | `http://192.168.4.1` |
| Connecteur de charge | USB-C |
| Entrée utilisateur | bouton avant et interrupteur d'alimentation latéral |
| Commentaires | écran plus bande LED RVB |
| Mesure de séance | les données de position, de vitesse/RPM, de temps, de distance, de courses et de fenêtre cible sont acceptées par la v2 actuelle API |
| Stockage d'étalonnage | la v2 actuelle API stocke des valeurs de 1,5 à 21,5 cm avec un écart d'au moins 2 cm ; ce sont des limites logicielles, pas des cibles |

## Non publié ici

Les dimensions exactes du boîtier, le poids, la composition chimique de la batterie/capacity, le temps de charge, l'autonomie nominale, la valeur nominale d'entrée USB, les limites environnementales, la protection contre la pénétration, le modèle de capteur/range, les limites électriques des accessoires et les modes de sécurité Wi-Fi pris en charge ne sont pas vérifiés dans ce référentiel.

Ne déduisez pas de limite électrique, environnementale ou médicale à partir d’un champ API ou d’une échelle d’interface utilisateur.
