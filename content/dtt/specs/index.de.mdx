Auf dieser Seite werden nur Werte aufgeführt, die von der aktuellen Produkt- und Anwendungsquelle unterstützt werden. Wenden Sie sich an den Support, wenn ein unveröffentlichter Wert Auswirkungen auf Installation, Reise, Reparatur oder Kompatibilität hat.

| Artikel | Verifizierte Informationen |
| ------------------- | ----------------------------------------------------------------- |
| Kontokopplung | kurzes Trainer ID wird beim Booten angezeigt |
| Netzwerkeinrichtung | 2,4 GHz Wi-Fi über das lokale **Trainer Setup**-Portal |
| Lokale Setup-Adresse | `http://192.168.4.1` |
| Ladeanschluss | USB-C |
| Benutzereingabe | vorderer Knopf und seitlicher Netzschalter |
| Feedback | Display plus RGB-LED-Streifen |
| Sitzungsmessung | Position, Geschwindigkeit/RPM, Zeit, Distanz, Hübe und Zielfensterdaten werden von der aktuellen v2 API | akzeptiert
| Kalibrierungsspeicher | aktuelle Version 2 API speichert Werte von 1,5–21,5 cm mit einem Abstand von mindestens 2 cm; Dies sind Softwaregrenzen, keine Verwendungsziele |
