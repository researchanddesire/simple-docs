Op deze pagina worden alleen waarden vermeld die worden ondersteund door de huidige product- en applicatiebron. Neem contact op met de ondersteuning als een niet-gepubliceerde waarde van invloed is op de installatie, het reizen, de reparatie of de compatibiliteit.

| Artikel | Geverifieerde informatie |
| ------------------ | ---------------------------------------------------------------------------------------------- |
| Accountkoppeling | korte Trainer ID weergegeven tijdens opstarten |
| Netwerkconfiguratie | 2,4 GHz Wi-Fi via het lokale **Trainer Setup**-portaal |
| Lokaal insteladres | `http://192.168.4.1` |
| Oplaadconnector | USB-C |
| Gebruikersinvoer | knop aan de voorzijde en aan/uit-schakelaar aan de zijkant |
| Feedback | display plus RGB LED-strip |
| Sessiemeting | positie, snelheid/RPM, tijd, afstand, slagen en doelvenstergegevens worden geaccepteerd door de huidige v2 API |
| Kalibratieopslag | huidige v2 API slaat waarden van 1,5–21,5 cm op met een tussenruimte van minimaal 2 cm; dit zijn softwaregrenzen, geen gebruiksdoelen |

## Niet hier gepubliceerd

Exacte afmetingen van de behuizing, gewicht, batterijchemie/capacity, oplaadtijd, nominale looptijd, USB ingangswaarde, omgevingslimieten, bescherming tegen binnendringing, sensormodel/range, elektrische limieten van accessoires en ondersteunde Wi-Fi beveiligingsmodi zijn niet geverifieerd in deze repository.

Leid geen elektrische, omgevings- of medische limiet af op basis van een API-veld of UI-schaal.
