Templates are made from segments. Choose the mode by the behavior you want to practice, then lower its targets until you can remain in control.

## Comparison

| Mode                                         | Primary task                                       | Main target                     | Current server measurement               | Start here when…                                           |
| -------------------------------------------- | -------------------------------------------------- | ------------------------------- | ---------------------------------------- | ---------------------------------------------------------- |
| [Repetition](/dtt/training-modes/repetition) | repeat a target movement                           | repetitions, pace, depth/window | strokes, time in window, RPM, depth      | you want a structured repeated motion                      |
| [Endurance](/dtt/training-modes/endurance)   | remain in a target zone                            | duration and position window    | active time and time in window           | you want a controlled hold                                 |
| [Freeform](/dtt/training-modes/freeform)     | choose your movement while following a pace target | average RPM and duration        | active time, time in window, average RPM | you want self-directed movement                            |
| [Bounce](/dtt/training-modes/bounce)         | control both directions of a cycle                 | repetitions, pace, depth/window | strokes, time in window, RPM, depth      | you can already control repeated motion in both directions |

<Callout type="warn">

No mode, grade, or points formula defines a medically safe depth, duration, speed, or progression. Stop for pain, breathing difficulty, dizziness, nausea, loss of control, or any concerning symptom.

</Callout>

## Current points calculation

The v2 completion API calculates an accuracy factor as `time inside target window ÷ total play time`, clamped from 0 to 1 (displayed here as 0–100%). The formulas below use that 0-to-1 factor.

- Repetition and Bounce base points: completed repetitions × 2 × accuracy factor.
- Endurance and Freeform base points: active seconds × 0.5 × accuracy factor.
- A configured toy length can apply a size multiplier after the base calculation.

The server rounds points upward. This is implementation behavior reviewed August 16, 2026 and can change; the dashboard result is authoritative.

## Create a template

1. Open the intended account and paired Trainer.
2. Create or edit a template.
3. Add one segment for the first test.
4. Select the installed toy and conservative targets.
5. Save and confirm the active template.
6. Fetch it online and review the device summary before starting.
