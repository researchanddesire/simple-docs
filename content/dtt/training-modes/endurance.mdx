---
title: "Endurance Mode"
description: "Configure and run a controlled hold while measuring active time and time inside the target window."
---

Endurance asks you to remain within a target position window for a configured duration. It emphasizes controlled position rather than repeated movement.

## Configure

1. Add one **Endurance** segment.
2. Select the installed toy.
3. Choose a shallow, comfortable position window and a duration you can stop well before fatigue.
4. Save, activate, fetch, and calibrate.

No default duration in this guide is a medical recommendation.

## Run

Move gradually into the target window and remain only while you can breathe and move away freely. Do not hold your breath or use restraints. Leave the target and stop when needed, regardless of the grade.

## Result and points

The current v2 server records active time, time inside and outside the target window, depth, and related statistics. For a nonzero session, base points are `active seconds × 0.5 × accuracy factor`, where the factor is time inside the target window divided by total play time and clamped from 0 to 1. The server rounds upward before any toy multiplier.

## Troubleshooting

| Symptom                        | Action                                                    |
| ------------------------------ | --------------------------------------------------------- |
| frequent boundary changes      | widen or reposition the window within a comfortable range |
| cannot maintain the hold       | reduce duration and position target                       |
| discomfort or breathing change | stop immediately and move away                            |
| result missing                 | verify online completion; do not assume offline recovery  |
