title: "Freeform Mode"
description: "Use self-directed movement while the Deep Throat Trainer measures pace, active time, and target-window accuracy."
---

Freeform lets you choose the motion while following the configured pace target. It still records a structured result; “freeform” does not remove the need for calibration, control, or stopping.

## Configure

1. Add one **Freeform** segment.
2. Select the installed toy.
3. Choose a conservative pace target and duration.
4. Save, activate, fetch, and review the device summary.

The UI may label pace-oriented Freeform behavior differently by firmware. Use the current editor and device text rather than a historical “Speed mode” promise.

## Run

Choose a rhythm and range you can control. Use the displayed average RPM/target feedback as information, not a demand to accelerate. Stop immediately when breathing, comfort, mount stability, or control changes.

## Result and points

The current v2 API records active time, average RPM, distance, strokes, depth range, and time in the target window. For a nonzero session, base points are `active seconds × 0.5 × accuracy factor`, where the factor is time in the target window divided by total play time and clamped from 0 to 1. The server rounds upward before any toy multiplier.

## Offline boundary

Cached playback may be available, but result persistence is not guaranteed until the session appears in the dashboard. See [Offline mode](/dtt/technical/offline-mode).

## Troubleshooting

| Symptom                   | Action                                                            |
| ------------------------- | ----------------------------------------------------------------- |
| average pace is unstable  | lower the target and use a smaller controlled range               |
| feedback does not respond | verify toy selection, sensor path, and calibration                |
| expected result is absent | reconnect, run an online test, and follow results troubleshooting |
