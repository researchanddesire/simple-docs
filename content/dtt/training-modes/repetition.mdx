---
title: "Repetition Mode"
description: "Configure and run repeated target movements while tracking strokes, position, pace, and time in the target window."
---

Repetition uses repeated movement toward and away from a target. The current server derives completed repetitions from measured strokes and scores time in the target window.

## Configure

1. Add one **Repetition** segment to a template.
2. Select the toy that is physically installed.
3. Set a low repetition count, comfortable range, pace, and target window.
4. Save and activate the template.
5. Fetch it online and calibrate when prompted.

The exact editor labels can vary. Review the device’s segment summary before starting.

## Run

Follow the target using smooth movement you can stop at any point. Use the screen direction with the LED feedback. A mismatch is a reason to slow or stop, not to force depth or speed.

<Callout type="success" title="Success">

The device reaches the grade/completion screen, and an online session appears with the expected Repetition segment.

</Callout>

## Result and points

For the current v2 API, completed repetitions are `ceil(strokes ÷ 2)`. For a nonzero session, base points are `completed repetitions × 2 × accuracy factor`, where the factor is time in the target window divided by total play time and clamped from 0 to 1. A toy multiplier can apply afterward, and the server rounds upward.

## Troubleshooting

| Symptom                           | Action                                                         |
| --------------------------------- | -------------------------------------------------------------- |
| cannot match the target           | lower pace, range, or repetition count                         |
| feedback seems reversed           | stop, verify toy assignment, and recalibrate                   |
| segment repeats after a low grade | check pass/fail and repeat settings in the template            |
| result is missing                 | use [Check session results](/dtt/quick-start/checking-results) |
