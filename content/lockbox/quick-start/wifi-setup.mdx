---
title: "Manual Lockbox Wi-Fi Setup"
description: "Connect a Lockbox to a 2.4 GHz Wi-Fi network when automatic Bluetooth provisioning is unavailable."
---

This is a fallback. For a new device, use [automatic Bluetooth pairing](/lockbox/quick-start/pairing) first; it can provision Wi-Fi during pairing.

## Requirements

- The Lockbox is powered and unlocked.
- You have a phone or computer with Wi-Fi.
- You know the name and password of a 2.4 GHz network.
- The network does not require a browser sign-in page.

## Connect manually

1. On the Lockbox, open **Settings → Wi-Fi Settings**.

![Wi-Fi Settings selected on the Lockbox](./images/lockbox-wifi-settings-unannotated.webp)

2. On your phone or computer, open Wi-Fi settings and join the setup network shown on the Lockbox.

![Lockbox Setup network in a Wi-Fi network list](./images/wifi-setup-lockbox-setup-annotated-png.webp)

3. If the configuration page does not open automatically, return to the Lockbox screen and use the address or QR code it provides.
4. Choose **Configure Wi-Fi**, select your 2.4 GHz network, enter its password, and save.

![Lockbox Wi-Fi configuration portal](./images/lockbox-wifi-manager-annotated.webp)

5. Wait for the Lockbox to leave setup mode and reconnect.

<Callout type="success" title="Confirm success">

The Wi-Fi status becomes connected. If the Lockbox is already paired, also confirm the dashboard reports it online. See [Status Symbols](/lockbox/using/symbols) for the difference.

</Callout>

## If it does not connect

- Re-enter the network name and password carefully.
- Confirm the chosen network supports 2.4 GHz.
- Move the Lockbox closer to the router for setup.
- Try a simple mobile hotspot to distinguish a Lockbox problem from a router problem.
- Follow [E-Lock 10](/lockbox/errors/e-lock-10) or [Connectivity Troubleshooting](/lockbox/support/connectivity-troubleshooting).
