---
title: „Manuelles Lockbox Wi-Fi Setup“
description: „Verbinden Sie einen Lockbox mit einem 2,4-GHz-Wi-Fi-Netzwerk, wenn die automatische Bluetooth-Bereitstellung nicht verfügbar ist.“
---

Dies ist ein Rückfall. Verwenden Sie für ein neues Gerät zuerst [automatic Bluetooth pairing](/lockbox/quick-start/pairing); Es kann Wi-Fi während des Pairings bereitstellen.

## Anforderungen

- Der Lockbox ist mit Strom versorgt und entsperrt.
- Sie haben ein Telefon oder einen Computer mit Wi-Fi.
- Sie kennen den Namen und das Passwort eines 2,4-GHz-Netzwerks.
- Das Netzwerk erfordert keine Browser-Anmeldeseite.

## Manuell verbinden

1. Öffnen Sie auf dem Lockbox **Einstellungen → Wi-Fi-Einstellungen**.

![Wi-Fi Settings selected on the Lockbox](./images/lockbox-wifi-settings-unannotated.webp)

2. Öffnen Sie auf Ihrem Telefon oder Computer die Wi-Fi-Einstellungen und treten Sie dem auf dem Lockbox angezeigten Setup-Netzwerk bei.

![Lockbox Setup network in a Wi-Fi network list](./images/wifi-setup-lockbox-setup-annotated-png.webp)

3. Wenn die Konfigurationsseite nicht automatisch geöffnet wird, kehren Sie zum Bildschirm Lockbox zurück und verwenden Sie die dort angegebene Adresse oder QR code.
4. Wählen Sie **Configure Wi-Fi**, wählen Sie Ihr 2,4-GHz-Netzwerk aus, geben Sie das Passwort ein und speichern Sie es.

![Lockbox Wi-Fi configuration portal](./images/lockbox-wifi-manager-annotated.webp)

5. Warten Sie, bis der Lockbox den Setup-Modus verlässt und erneut eine Verbindung herstellt.

<Callout type="success" title="Bestätigen Sie den Erfolg">

Der Status Wi-Fi wird verbunden. Wenn der Lockbox bereits gekoppelt ist, bestätigen Sie auch, dass das Dashboard dies online meldet. Den Unterschied finden Sie unter [Status Symbols](/lockbox/using/symbols).

</Callout>

## Wenn keine Verbindung hergestellt wird

- Geben Sie den Netzwerknamen und das Passwort erneut sorgfältig ein.
- Bestätigen Sie, dass das ausgewählte Netzwerk 2,4 GHz unterstützt.
- Bewegen Sie den Lockbox für die Einrichtung näher an den Router.
- Versuchen Sie es mit einem einfachen mobilen Hotspot, um ein Lockbox-Problem von einem Router-Problem zu unterscheiden.
- Folgen Sie [E-Lock 10](/lockbox/errors/e-lock-10) oder [Connectivity Troubleshooting](/lockbox/support/connectivity-troubleshooting).
