Beginnen Sie mit einer kurzen Probesperre. Machen Sie die erste Sitzung nicht zu einer langen Sperre, einer Permalock-Sitzung oder einer öffentlichen Abstimmungssitzung.

## Test-Lock-Preflight

- Lesen Sie [Lockbox Safety and Emergency Access](/lockbox/safety).
- Bestätigen Sie, dass Lockbox [paired and online](/lockbox/quick-start/pairing) ist.
- Lassen Sie Lockbox geöffnet, bis Sie jeden Release-Pfad überprüft haben.
- Stellen Sie sicher, dass der Lockee den Lockbox und seine Tasten physisch erreichen kann.
- Wenn ein Schlüsselinhaber beteiligt ist, füllen Sie das [Keyholder preflight](/lockbox/quick-start/keyholder-guide#keyholder-preflight) aus.

## Starten Sie eine kurze Selbstsperre

1. Melden Sie sich im Dashboard an und öffnen Sie **Chastity Lockbox**.

![Chastity Lockbox selected in the dashboard](./images/dashboard-self-lock-annotated.webp)

2. Wählen Sie die Option Selbstsperre.

![Self-lock option in the Lockbox dashboard](./images/self-lock-selection-annotated.webp)

3. Wählen Sie für diesen Test eine kurze Dauer und lassen Sie die erweiterten Funktionen deaktiviert.
4. Sehen Sie sich die Zusammenfassung an und starten Sie dann die Sitzung.

![Start Lock Session action for a self-lock](./images/self-lock-start-lock-session-annotated.webp)

5. Stecken Sie den Schlüssel in den Lockbox, schließen Sie den Deckel/backplate und vergewissern Sie sich, dass der Mechanismus ohne Behinderung den verriegelten Zustand erreicht.

<Callout type="success" title="Bestätigen Sie, dass der Test aktiv ist">

Das physische Lockbox und das Dashboard sollten beide eine aktive Sitzung anzeigen. Wenn sie nicht einverstanden sind, fahren Sie nicht mit einer längeren Sperre fort; Verwenden Sie [Connectivity Troubleshooting](/lockbox/support/connectivity-troubleshooting).

</Callout>

## Testen Sie jeden Release-Pfad

Während des Kurztests:

1. Bestätigen Sie, dass die normale Aktion zum Beenden der Sitzung funktioniert.
2. Wenn ein Schlüsselinhaber beteiligt ist, lassen Sie ihn einen separaten kurzen Test abschließen und bestätigen, dass das physische Gerät entsperrt wird.
3. Suchen Sie die lokale Notfall-Entriegelung und überprüfen Sie den Bestätigungsbildschirm, ohne dies als Strafe zu betrachten.
4. Halten Sie den [hardware backplate procedure](/lockbox/support/emergency-backplate) offline verfügbar.

## Erstellen Sie später eine wiederverwendbare Vorlage

Nach einem erfolgreichen Test können Sie im Dashboard Lockbox eine wiederverwendbare Sperrvorlage erstellen oder bearbeiten.

![Lock template editor with session settings](./images/creating-and-editing-a-lock-annotated.webp)

Überprüfen Sie jede Option vor dem Speichern mit allen Betroffenen. Funktionen wie Pausen, versteckte Zeit, öffentliche Abstimmung, Kontrolle über den Schlüsselhalter und Verfügbarkeit von Notfallentriegelung verändern das Erlebnis und den Wiederherstellungspfad.

![Save action in the Lockbox template editor](./images/creating-and-editing-a-lock-save-annotated.webp)

<Callout type="warn">

Aktivieren Sie keine Option, die Sie nicht getestet haben oder die Sie nicht verstehen. Das Dashboard und die verfügbaren Optionen können sich ändern; Wenn eine Einstellung von dieser Anleitung abweicht, halten Sie an und wenden Sie sich an den Support, bevor Sie sich darauf verlassen.

</Callout>
