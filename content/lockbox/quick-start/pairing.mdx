title: "Pair Your Lockbox"
description: "Pair a Lockbox and provision 2.4 GHz Wi-Fi with the recommended Bluetooth flow or a manual code."
---

Automatic Bluetooth pairing is the recommended setup method. It pairs the Lockbox to your dashboard account and sends Wi-Fi credentials in one flow.

## What you need

- A powered, unlocked Lockbox that is not paired to another account
- A dashboard account
- Chrome or Edge on a desktop or laptop for automatic pairing
- A nearby 2.4 GHz Wi-Fi network and its password

<Callout type="info">

Bluetooth is used only for nearby setup. After pairing, normal dashboard communication uses the Lockbox's Wi-Fi connection.

</Callout>

## Recommended: automatic Bluetooth pairing

1. Sign in at [dashboard.researchanddesire.com](https://dashboard.researchanddesire.com).
2. Open **Settings → My Devices**.

![Dashboard navigation with Settings and My Devices labeled](./images/lkbx-pairing-settings-dropdown-annotated.webp)

3. Choose **Pair a Lockbox**, then choose the option to scan for a nearby Lockbox.

![Pair a Lockbox action in My Devices](./images/pair-a-lockbox.webp)

4. In the browser Bluetooth chooser, select your Lockbox and approve the connection.
5. When asked, enter the name and password for the 2.4 GHz Wi-Fi network the Lockbox should use.
6. Wait for the dashboard to report success and for the Lockbox to restart or return to its normal screen.

<Callout type="success" title="Confirm pairing succeeded">

The Lockbox appears in **My Devices**, and the device status becomes online after it connects to Wi-Fi. Status can take a short time to update; use [Check Online Status](/lockbox/support/online-status) if the two displays disagree.

</Callout>

## Manual pairing code

Use this method if Web Bluetooth is unavailable. Complete [manual Wi-Fi setup](/lockbox/quick-start/wifi-setup) first.

1. On the Lockbox, open **Settings → Pairing**.

![Pairing selected in the Lockbox Settings menu](./images/lkbx-pairing-selection-unannotated.webp)

2. Note the unique pairing code shown on the Lockbox.

![Pairing code shown on the Lockbox display](./images/lkbx-pairing-code-annotated.webp)

3. In the dashboard, open **Settings → My Devices → Pair a Lockbox**.
4. Enter the code and choose **Pair device**.

![Pairing-code entry in the dashboard](./images/lockbox-pairing-code-entry-annotated.webp)

5. Confirm the device appears in **My Devices** and becomes online.

## If pairing does not work

| Symptom                                      | Next action                                                                                               |
| -------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| Browser does not offer Bluetooth             | Use current Chrome or Edge on a desktop/laptop and allow Bluetooth permission                             |
| No Lockbox appears in the chooser            | Confirm it is powered, nearby, unlocked, and not already paired; restart it once                          |
| Wi-Fi provisioning fails                     | Confirm 2.4 GHz credentials, then use [manual Wi-Fi setup](/lockbox/quick-start/wifi-setup)               |
| Dashboard says it belongs to another account | Ask the current owner to unpair it; if that is impossible, contact support rather than repeatedly pairing |
| Device is listed but offline                 | Follow [Connectivity Troubleshooting](/lockbox/support/connectivity-troubleshooting)                      |

Never share a pairing code publicly. If ownership or access is disputed, stop setup and email [support@researchanddesire.com](https://www.researchanddesire.com/pages/contact-us).
