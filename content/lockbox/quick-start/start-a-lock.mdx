---
title: "Start Your First Lock"
description: "Run a short Lockbox test session, verify release and emergency access, then prepare a reusable lock template."
---

Start with a short test lock. Do not make the first session a long lock, Permalock session, or public-voting session.

## Test-lock preflight

- Read [Lockbox Safety and Emergency Access](/lockbox/safety).
- Confirm the Lockbox is [paired and online](/lockbox/quick-start/pairing).
- Keep the Lockbox open until you have reviewed every release path.
- Make sure the Lockee can physically reach the Lockbox and its buttons.
- If a Keyholder is involved, complete the [Keyholder preflight](/lockbox/quick-start/keyholder-guide#keyholder-preflight).

## Start a short self-lock

1. Sign in to the dashboard and open **Chastity Lockbox**.

![Chastity Lockbox selected in the dashboard](./images/dashboard-self-lock-annotated.webp)

2. Choose the self-lock option.

![Self-lock option in the Lockbox dashboard](./images/self-lock-selection-annotated.webp)

3. Select a short duration and leave advanced features off for this test.
4. Review the summary, then start the session.

![Start Lock Session action for a self-lock](./images/self-lock-start-lock-session-annotated.webp)

5. Put the key in the Lockbox, close the lid/backplate, and confirm the mechanism reaches the locked state without obstruction.

<Callout type="success" title="Confirm the test is active">

The physical Lockbox and dashboard should both show an active session. If they disagree, do not continue to a longer lock; use [Connectivity Troubleshooting](/lockbox/support/connectivity-troubleshooting).

</Callout>

## Test every release path

During the short test:

1. Confirm the normal end-session action works.
2. If a Keyholder is involved, have them end a separate short test and confirm the physical device unlocks.
3. Locate local Emergency Unlock and review its confirmation screen without treating it as a punishment.
4. Keep the [hardware backplate procedure](/lockbox/support/emergency-backplate) available offline.

## Create a reusable template later

After a successful test, you can create or edit a reusable lock template in the Lockbox dashboard.

![Lock template editor with session settings](./images/creating-and-editing-a-lock-annotated.webp)

Review each option with everyone affected before saving. Features such as breaks, hidden time, public voting, Keyholder control, and Emergency Unlock availability change the experience and recovery path.

![Save action in the Lockbox template editor](./images/creating-and-editing-a-lock-save-annotated.webp)

<Callout type="warn">

Do not enable an option you have not tested or do not understand. The dashboard and available options can change; if a setting is different from this guide, stop and contact support before relying on it.

</Callout>
