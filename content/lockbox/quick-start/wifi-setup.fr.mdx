---
title: "Configuration manuelle Lockbox Wi-Fi"
description: "Connectez un Lockbox à un réseau Wi-Fi 2,4 GHz lorsque le provisionnement automatique Bluetooth n'est pas disponible."
---

C'est une solution de repli. Pour un nouvel appareil, utilisez d'abord [automatic Bluetooth pairing](/lockbox/quick-start/pairing) ; il peut fournir Wi-Fi pendant l'appairage.

## Exigences

- Le Lockbox est alimenté et déverrouillé.
- Vous disposez d'un téléphone ou d'un ordinateur avec Wi-Fi.
- Vous connaissez le nom et le mot de passe d'un réseau 2,4 GHz.
- Le réseau ne nécessite pas de page de connexion du navigateur.

## Connectez-vous manuellement

1. Sur le Lockbox, ouvrez **Paramètres → Wi-Fi Paramètres**.

![Wi-Fi Settings selected on the Lockbox](./images/lockbox-wifi-settings-unannotated.webp)

2. Sur votre téléphone ou votre ordinateur, ouvrez les paramètres Wi-Fi et rejoignez le réseau de configuration affiché sur le Lockbox.

![Lockbox Setup network in a Wi-Fi network list](./images/wifi-setup-lockbox-setup-annotated-png.webp)

3. Si la page de configuration ne s'ouvre pas automatiquement, revenez à l'écran Lockbox et utilisez l'adresse ou QR code qu'elle fournit.
4. Choisissez **Configurer Wi-Fi**, sélectionnez votre réseau 2,4 GHz, saisissez son mot de passe et enregistrez.

![Lockbox Wi-Fi configuration portal](./images/lockbox-wifi-manager-annotated.webp)

5. Attendez que le Lockbox quitte le mode configuration et reconnectez-vous.

<Callout type="success" title="Confirmer le succès">

L'état Wi-Fi devient connecté. Si le Lockbox est déjà couplé, confirmez également que le tableau de bord le signale en ligne. Voir [Status Symbols](/lockbox/using/symbols) pour la différence.

</Callout>

## S'il ne se connecte pas

- Ressaisissez soigneusement le nom du réseau et le mot de passe.
- Confirmez que le réseau choisi prend en charge 2,4 GHz.
- Rapprochez le Lockbox du routeur pour la configuration.
- Essayez un simple point d'accès mobile pour distinguer un problème Lockbox d'un problème de routeur.
- Suivez [E-Lock 10](/lockbox/errors/e-lock-10) ou [Connectivity Troubleshooting](/lockbox/support/connectivity-troubleshooting).
