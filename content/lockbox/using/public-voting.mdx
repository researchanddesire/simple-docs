---
title: "Lockbox Public Voting"
description: "Enable, share, monitor, limit, and disable Lockbox public voting with clear privacy and role boundaries."
---

Public voting creates a shareable link that lets visitors add or remove time from an active lock according to values configured for that session.

<Callout type="warn">

Everyone affected should agree on the audience, vote effects, minimum and maximum duration, and shutdown plan before the link is shared. Public voting must not remove access to breaks or emergency release.

</Callout>

## Roles and visibility

| Role        | What to verify                                                                       |
| ----------- | ------------------------------------------------------------------------------------ |
| Lockee      | Consents to the audience and configured effects; retains safety and emergency access |
| Keyholder   | Has permission to modify this session and knows how to disable voting or end it      |
| Self-locker | Configures and tests the limits before starting the active session                   |
| Voter       | Receives only the public voting view; logged-in identity may appear in activity      |

The public page exposes session details needed for voting. It must not expose account credentials, but sharing the link intentionally makes the voting view available to anyone who receives or forwards it.

## Enable and configure

1. In the dashboard, edit a Lockbox template, or open **Modify settings** for an eligible active or test session.

![Lockbox template editor where session features are configured](../quick-start/images/creating-and-editing-a-lock-annotated.webp)

2. Enable **Public Voting**.
3. Open its settings and configure:
   - **Time Plus**: seconds added by an increase vote;
   - **Time Minus**: seconds removed by a decrease vote;
   - **Maximum Lock Duration**: optional upper boundary; and
   - **Minimum Lock Duration**: optional lower boundary.

4. Review the final values with the Lockee and Keyholder before saving.

<Callout type="warn">

Without an upper or lower boundary, the current documentation says votes can continue changing the duration in that direction. Do not publish the link until the configured effects and boundaries are acceptable.

</Callout>

## Share the link

1. Open the active Lockbox session in the dashboard.
2. Find the **Public Voting** badge or share action.
3. Copy the link.
4. Open it in a private/incognito window before sharing.
5. Confirm the public view contains only information you intend to publish.

Treat the URL as public. Share it only in communities that match the agreed audience and assume it can be forwarded.

## Monitor activity

The Lockbox page can show counters for increase and decrease votes. The session activity history records vote direction, timestamp, and either a logged-in username or **Anonymous**.

The current documentation describes a per-session voting limit of one vote every 24 hours, tracked by account and IP address. Because abuse controls can change, rely on the live interface rather than using this as a guaranteed rate limit.

Check the physical Lockbox periodically. Votes apply to the session, but the dashboard can be ahead of an offline device.

## Disable voting and revoke the link

1. Open the active session settings.
2. Turn off **Public Voting** and save.
3. Confirm the badge/share action disappears.
4. Open the old link in a private window and confirm it no longer accepts votes.

Past vote events remain in activity history. Disabling voting cannot retract information already shared or copies of the URL.

## Safety and recovery

- If votes create an unsafe or unwanted situation, disable voting and end the session.
- If the dashboard cannot reach the Lockbox, use local controls and [Emergency Access](/lockbox/safety).
- If the public page exposes unexpected information or continues accepting votes after disabling, stop sharing and contact [support@researchanddesire.com](https://www.researchanddesire.com/pages/contact-us).
