Share a voting link so visitors can add or remove time from an active session.

## Enable and share

1. On the Lockbox page, open the current session's actions menu and select **Modify session**. To configure a future session, edit or create a Lockbox template instead.
2. Turn on **Enable public voting on lock duration**.
3. Select the settings button beside the switch and review the settings below.
4. Save. For an active session, return to its actions menu and select **Copy public voting link**.
5. Share the link with your visitors.

| Setting | Effect |
| --- | --- |
| **Increase Time Unit** | Time added by one upvote. |
| **Decrease Time Unit** | Time removed by one downvote. |
| **Minimum / Maximum Lock Duration** | Limits how far votes can change the session's duration. Without limits, votes can continue adding or removing time. |
| **Show in Public Links** | Adds the session to the public directory. Leaving it off does not block the direct link. |

<Callout type="warning" title="Check vote sizes before sharing">

Votes change the session deadline. Each time unit must be at least **15 minutes** in the current form.

</Callout>

<Callout type="info" title="Session settings and templates are separate">

Changing a template does not change the current session. **Modify session** is available to an R+D session keyholder, or for a test or pending session. A normal active-session wearer may only have add-time controls.

</Callout>

<Callout type="info" title="Using Chaster?">

New Chaster-created sessions start with Dashboard voting off; existing sessions keep their setting. Follow [Voting with Chaster](/lockbox/chaster/voting) for setup and sync warnings. Dashboard votes do not count toward Chaster's required Share links visits.

</Callout>

## Turn voting off or hide the listing

With full session-editing access, open **Modify session**, change the relevant switch, and save.

<Mermaid chart={`

    A["What do you want to change?"] --> B["Remove the directory listing"]
    A --> C["Turn off public voting"]
    B --> D["Turn off Show in Public Links"]
    D --> E["Direct-link voting remains available"]
    C --> F["Turn off Enable public voting<br/>on lock duration"]
    F --> G["Ordinary public access is restricted"]
`} />

<Callout type="warning" title="Hiding is not disabling">

Anyone with the direct link can still vote while public voting is on. Past votes stay in your activity history after voting is turned off. Chaster Share links is configured separately.

</Callout>

## Troubleshooting

| Problem | What to check |
| --- | --- |
| No voting switch or **Modify session** option | Open a template or a session you have permission to modify. Add-time access alone does not allow editing voting settings. |
| No **Copy public voting link** option | Enable voting on the current active session and save. A template setting alone is not enough. |
| The link is inactive | The session must be active. Ended or abandoned sessions cannot receive votes. |
| A visitor cannot vote again | Wait until the next voting time shown on the page. |
| Votes change too much time | Review both time units and the minimum and maximum duration. |
| A Dashboard vote reports a Chaster sync error | Check both deadlines before retrying; Dashboard changes may remain. See [Voting with Chaster](/lockbox/chaster/voting). |

## Optional vote activity

On the Lockbox page, **👍** counts votes to add time and **👎** counts votes to remove it. Counters appear when voting is enabled or a vote has been recorded.

For individual votes, open **Session activity → View more**. Each entry shows the vote direction, voter, and time alongside other session events. Signed-in voters appear by username; visitors who are not signed in appear as **Anonymous**.

## Optional voting limits and privacy

- Repeat votes are limited by account and IP address. When both are detected, the stricter limit applies. Follow the next voting time shown on the page.
- The public link shows session details. Review its public view before sharing.

## Optional points and rewards

Session owners and voters earn points from public voting. Point values decrease as more votes are cast throughout the day.
