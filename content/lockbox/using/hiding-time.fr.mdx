Le Chastity Lockbox comprend une fonction « Masquer la durée d'affichage » qui masque le temps restant dans votre session. Cela ajoute un élément d’incertitude et d’anticipation à votre expérience.

## Que fait "Masquer l'heure d'affichage"

Lorsque vous activez « Masquer la durée d'affichage », la durée de verrouillage restante est masquée dans tous les emplacements :

- **Page d'accueil du tableau de bord** : votre tableau de bord principal n'affichera pas le temps restant
- **Lockbox Page d'accueil** — La page spécifique au lockbox masque le compte à rebours
- **Lockbox Table d'activité** — Le journal d'activité omet le temps restant
- **Tableau de vote public** — Les électeurs ne peuvent pas voir le temps restant
- **Affichage de l'appareil physique** — L'écran du lockbox masque le compte à rebours
- **Notifications de vote** — Les ajustements de temps à partir des votes s'affichent sans durée spécifique

<Callout type="info">

Votre session de verrouillage continue de fonctionner normalement même lorsque l'heure est masquée. Le compte à rebours s'exécute toujours en arrière-plan, vous ne pouvez tout simplement pas le voir.

</Callout>
## Qui peut activer ce paramètre

Pour un auto-verrouillage, configurez le paramètre avant la session. Au cours d'une session gérée par le détenteur de clé, le tableau de bord actuel permet au détenteur de clé de le modifier. Confirmez le paramètre actif sur les deux comptes avant de verrouiller.

<Callout type="warn">

Le temps de masquage ne doit pas masquer les conseils de sécurité, l'état de verrouillage physique de l'appareil, les commandes de communication ou les instructions de déverrouillage d'urgence. Le Lockee devrait toujours savoir comment accéder à la clé sans voir le compte à rebours.

</Callout>

## Comment activer "Masquer l'heure d'affichage"

### Étape 1 : Naviguez pour verrouiller les paramètres du modèle

Accédez au tableau de bord et ouvrez la page des paramètres de votre modèle de verrouillage.

### Étape 2 : Recherchez l'option de temps d'affichage

Localisez le paramètre « Masquer l'heure d'affichage » dans la configuration de votre modèle de verrouillage.

### Étape 3 : Activer le paramètre

Activez l'option "Masquer l'heure d'affichage".

<Callout type="success">

Pour les casiers automatiques, activez ceci **avant** de démarrer votre session. Les détenteurs de clés peuvent l'activer **à tout moment**.

</Callout>
### Étape 4 : Démarrez ou poursuivez votre verrouillage

Une fois activé, tous les affichages de temps se cachent sur le tableau de bord et sur votre appareil physique.

## Questions courantes

<Callout type="info" title="Puis-je réactiver l'affichage de l'heure pendant un verrouillage actif ?">

Si vous êtes auto-verrouillé, vous ne pouvez pas modifier ce paramètre pendant une session active. Cependant, si vous disposez d'un détenteur de clé, celui-ci peut activer ou désactiver ce paramètre à tout moment pendant votre session de verrouillage.

</Callout>
<Callout type="info" title="Mon détenteur de clé verra-t-il toujours le temps restant ?">

Oui. Votre détenteur de clé voit toujours le temps restant de son côté, même lorsqu'il est caché à votre vue. Cela leur permet de gérer efficacement votre session de verrouillage.

</Callout>
<Callout type="info" title="Que se passe-t-il si quelqu'un vote sur ma serrure ?">

Le vote continue de fonctionner normalement : les utilisateurs peuvent toujours ajouter ou supprimer du temps pour votre verrouillage. Cependant, lorsque les votes sont exprimés, vous ne verrez aucune information horaire dans les notifications. Vous saurez qu'un vote a eu lieu, mais pas l'impact temporel précis.

</Callout>
<Callout type="info" title="Puis-je voir mon historique de verrouillage après la fin de la session ?">

Oui. Une fois votre session de verrouillage terminée, vous pouvez voir l'historique complet, y compris toutes les informations temporelles, dans votre journal d'activité.

</Callout>
