---
title: „Verwenden von Lockbox-Funktionen“
description: „Wählen Sie ein Lockbox-Feature und verstehen Sie seine Rollen, Sichtbarkeit und Sicherheitsauswirkungen.“
---

Verwenden Sie diese Funktionen erst, nachdem Sie eine kurze Testsperre durchgeführt und [Lockbox Safety](/lockbox/safety) überprüft haben.

| Funktion | Zweck | Wichtige Grenze |
| ------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------ |
| [Take a Break](/lockbox/using/take-a-break) | Temporärer Schlüsselzugriff während einer aktiven Sitzung | Gesundheit und Notfallzugang haben Vorrang vor Zeitplänen oder Konsequenzen |
| [Hide Remaining Time](/lockbox/using/hiding-time) | Verstecke den Countdown vor dem Lockee | Sicherheits- und Notfallhinweise müssen verfügbar bleiben |
| [Public Voting](/lockbox/using/public-voting) | Lassen Sie Personen mit einem freigegebenen Link Einfluss auf eine Sitzung nehmen | Sehen Sie sich zuerst die Zielgruppe, die Beschränkungen und die Deaktivierung der Freigabe an |
| [Status Symbols](/lockbox/using/symbols) | Interpretieren Sie Sperre, Netzwerk und Batteriestatus | Ein Wi-Fi-Symbol allein bestätigt nicht die Dashboard-Konnektivität |
