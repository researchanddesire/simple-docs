## Avant de redémarrer

<Callout type="warn">

Ne redémarrez pas votre appareil pendant les mises à jour du micrologiciel, sauf si l'assistance vous le demande. L'interruption d'une mise à jour peut nécessiter une récupération manuelle.

</Callout>
<Callout type="info">

Le redémarrage n’annule pas les minuteries actives ni n’efface les paramètres de votre session. Votre appareil conserve son état verrouillé/unlocked lors des redémarrages. Si vous avez plutôt besoin d'économiser davantage de batterie, consultez <a href="/lockbox/device-states/sleep-mode">Mode veille</a>.

</Callout>
## Comment redémarrer

| Situation | Utiliser |
| ------------------------------------ | -------------------------------------------------------------- |
| L'appareil répond normalement | **Paramètres → Redémarrer l'appareil** |
| L'écran et les commandes ne répondent pas | Maintenez **Entrez/Lock** pendant 10 secondes |
| Un accès urgent à la clé est requis | Utilisez [Emergency Access](/lockbox/safety), pas de redémarrages répétés |
| La mise à jour Firmware est en cours | Attendez ou suivez les instructions d'assistance |

### Étape 1 : Utiliser le menu (recommandé)

Sur l'appareil, accédez à <strong>Paramètres → Redémarrer l'appareil</strong>, puis confirmez lorsque vous y êtes invité. L'appareil redémarrera automatiquement.

<Callout type="success">

Vous devriez voir le cycle d'alimentation de l'appareil et revenir à l'écran approprié (tentative de verrouillage ou menu principal) en fonction de son état antérieur.

</Callout>
### Étape 2 : Utilisez la réinitialisation matérielle (pour les appareils qui ne répondent pas)

Si votre appareil ne répond pas, maintenez enfoncé le bouton <strong>Enter/Lock</strong> pendant <strong>10 secondes</strong>. L'écran deviendra vide et l'appareil redémarrera automatiquement.

<Callout type="success">

Après le redémarrage, confirmez l'une des opérations suivantes :

- S'il a été précédemment verrouillé, l'appareil tente de réenclencher le verrouillage.
- Si précédemment déverrouillé, le menu principal apparaît

</Callout>
<Callout type="warn">

Utilisez la réinitialisation matérielle uniquement lorsque l'appareil ne répond pas. Pour les redémarrages normaux, utilisez l'option de menu.

</Callout>
## À quoi s'attendre après un redémarrage

| Avant le redémarrage | Après le redémarrage |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| État du verrouillage physique | Conservé; un appareil précédemment verrouillé tente de réenclencher le verrouillage |
| Minuterie active | Continue sans réinitialiser |
| Paramètres de session | Préservé |
| Appareil précédemment déverrouillé | Retourne au menu principal |
| Connexion Wi-Fi | Se reconnecte lorsque le réseau enregistré est disponible ; confirmer l'indicateur d'état avant de compter sur les télécommandes |

## Dépannage

<Callout type="info" title="L'appareil ne se rallume pas">

- Branchez sur l'alimentation USB pendant au moins 10 minutes, puis maintenez <strong>Enter/Lock</strong> pendant 10 secondes.
- Essayez un autre câble USB‑C et une autre source d'alimentation

</Callout>
<Callout type="info" title="Le verrouillage ne s'est pas réenclenché après le redémarrage">

- Assurez-vous que rien n'obstrue le loquet
- Si vous voyez une invite d'étalonnage, suivez les étapes à l'écran ou visitez <a href="/lockbox/device-states/calibration">Calibration</a>

</Callout>
<Callout type="info" title="L'appareil affiche l'étalonnage après le redémarrage">

- Cela peut se produire après le flashage du firmware ; terminez l'étalonnage et l'appareil reprendra son fonctionnement normal
- En savoir plus sur <a href="/lockbox/device-states/calibration">Calibration</a>

</Callout>
<Callout type="info" title="L'appareil apparaît hors ligne après le redémarrage">

- Reconnectez-vous à Wi-Fi (2,4 GHz uniquement) à l'aide du <a href="/lockbox/quick-start/wifi-setup">Manual Wi-Fi Setup</a>

</Callout>
