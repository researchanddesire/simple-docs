---
title: "Break State Reference"
description: "Reference how the Lockbox behaves while a scheduled break is active."
---

This page describes the device state. For the complete procedure, use [Take a Break](/lockbox/using/take-a-break).

| State           | Expected behavior                                                                      |
| --------------- | -------------------------------------------------------------------------------------- |
| Break available | The active session permits a break and the waiting interval has passed                 |
| Break active    | The device unlocks and displays the remaining break time                               |
| Break completed | Returning the key and ending the break re-locks the device and reports completion      |
| Break overdue   | The device reports that the break is late and the Keyholder may receive a notification |

The active template determines whether breaks are available and their timing. Test the workflow during a short lock before relying on it in a longer session.

<Callout type="warn">

A break timer or overdue record must never prevent urgent access or necessary care. Use [Emergency Access](/lockbox/safety) whenever a scheduled break is insufficient.

</Callout>
