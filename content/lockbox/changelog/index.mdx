User-visible releases are listed newest first. The source notes did not include verified release dates, so none are invented here.

<Callout type="info">

The Lockbox does not currently expose a complete public release ledger with dates, compatibility, and rollback packages. Before changing firmware channels or reinstalling a version, contact [support@researchanddesire.com](https://www.researchanddesire.com/pages/contact-us).

</Callout>

## v1.17.66

- Added automatic pairing from Chrome or Edge with Web Bluetooth.
- Added Wi-Fi provisioning during Bluetooth pairing, so manual Wi-Fi setup is no longer required for the recommended flow.
- Improved unpairing so an unpaired Lockbox restarts and advertises for pairing again.

## v1.17.63

- Restored the battery status icon.
- Added fallback behavior when the INA219 battery sensor is unavailable.

## v1.17.62

- Reverted the HTTP-client reuse and boot-sequence changes from v1.17.61 after stability concerns.

## v1.17.58

- Disabled the battery icon in the status bar. It was restored in v1.17.63.

## v1.17.51

- Added configurable minimum and maximum duration boundaries for Public Voting.

## v1.17.49

- Redesigned the startup screen.
- Added onboarding states for welcome, Wi-Fi setup, and device pairing.
- Improved text wrapping and cursor positioning.

## Known issues and recovery

If a documented feature does not appear, record the version displayed on the Lockbox and contact support. Do not assume that a lower version is compatible with current dashboard behavior. Follow [Flash or Recover Lockbox Firmware](/lockbox/support/flashing) only when support identifies the correct package and whether local data should be erased.
