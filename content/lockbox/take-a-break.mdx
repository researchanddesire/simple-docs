# Request or start a break

Breaks must be enabled for the active session by you or your keyholder. If they are not enabled, **Take a Break** does not appear.

1. Wake the Lockbox, open the lock menu, and choose **Take a Break**.
2. Review the break information and start the break. The Lockbox unlocks so you can remove the key.
3. Return the key before the displayed timer expires.
4. Close the backplate and select **End Break**. The device locks and confirms the end of the break to the Dashboard.

A break is temporary. If its timer expires while the key is out, the keyholder is notified and the account records a failed break. This does not apply to a test lock.

Use the emergency release instead if there is pain, injury, a medical concern, or any situation where waiting is unsafe. See [Emergency Unlock](/lockbox/emergency-unlock).
