# Use the emergency menu

1. While the device is locked, press and hold **Enter/Lock** for about two seconds.
2. Choose **Emergency Unlock**.
3. Read the confirmation screen and confirm the action.
4. Open the backplate and remove the key.

The lock opens immediately, the session ends, and a 24-hour cooldown prevents a new lock from starting.

Use the emergency option immediately if there is pain, injury, a medical concern, or another unsafe condition. Do not wait for a timer or remote response.

# If the device cannot unlock

The software option may have been disabled in the session settings. If it is unavailable and access cannot wait, use the backup hardware release prepared before the session. The backplate release is destructive and requires replacing the backplate, so treat it as a last resort.

After any emergency unlock, stop using the Lockbox until you understand why it was needed and have checked the device and release mechanism.
