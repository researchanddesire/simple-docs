# What you need

- Your Lockbox and a USB-C data cable.
- A 2.4 GHz Wi-Fi network.
- An R+D Dashboard account if you want remote features.

Charge the Lockbox for at least 30 minutes before setup.

# Pair automatically — recommended

1. Power on an unpaired Lockbox.
2. In Chrome or Edge on a desktop or laptop, sign in to the [R+D Dashboard](https://dashboard.researchanddesire.com/).
3. Open **Settings → Devices → Pair Lockbox**. The **Automatic** tab opens by default.
4. Select **Scan for Lockbox**, choose **LKBX** in the browser picker, and connect.
5. If asked, select a saved 2.4 GHz Wi-Fi network or enter its name and password.
6. Wait for confirmation, then select **Continue**.

Automatic pairing is not available in Firefox, Safari, or most mobile browsers. The Lockbox only advertises over Bluetooth while it is unpaired.

# Pair with a code

Manual pairing works in any browser, but the Lockbox must already be connected to Wi-Fi.

1. On the Lockbox, open **Settings → Pairing**.
2. Scan the QR code or note the six-character pairing code.
3. In the Dashboard, open **Settings → Devices → Pair Lockbox → Enter Code**.
4. Enter the code and select **Pair**.

The code changes whenever the Lockbox restarts. Always use the code currently on its screen.

Keep the device charged and confirm the physical release method before starting a lock.
