# The Lockbox does not wake

Connect it to power with a USB-C cable and charge for at least 30 minutes. Then press **Enter/Lock** again.

# Pairing or Wi-Fi fails

- Use a 2.4 GHz Wi-Fi network.
- Keep the Lockbox near the router during setup.
- Use current Chrome or Edge for automatic browser pairing.
- If automatic pairing does not appear, use the code shown on the Lockbox.
- Restart the Lockbox and retry from **Settings → Devices**.

# It will not unlock

If waiting is unsafe, use [Emergency Unlock](/lockbox/emergency-unlock) and your backup release plan. Do not rely on Wi-Fi or remote access as the only emergency method.

For continued problems, email [support@researchanddesire.com](mailto:support@researchanddesire.com) with the message on the display and the step that failed.
