Start with the symptom you can see. If urgent key access is involved, use the emergency route first.

| What you need                                     | Start here                                                                    |
| ------------------------------------------------- | ----------------------------------------------------------------------------- |
| Urgent access to the key                          | [Safety and Emergency Access](/lockbox/safety)                                |
| Software unlock is unavailable                    | [Hardware Backplate Emergency Access](/lockbox/support/emergency-backplate)   |
| Dashboard and device disagree about online status | [Check Online Status](/lockbox/support/online-status)                         |
| Wi-Fi, dashboard sync, or remote commands fail    | [Connectivity Troubleshooting](/lockbox/support/connectivity-troubleshooting) |
| An error code is on screen                        | [Lockbox Error Codes](/lockbox/errors)                                        |
| Support instructed you to reinstall firmware      | [Flash or Recover Firmware](/lockbox/support/flashing)                        |

<Callout type="warn">

Do not flash, reset, or repeatedly restart a Lockbox when urgent access is required. Use the documented emergency access path first.

</Callout>

## Contact support

Email [support@researchanddesire.com](mailto:support@researchanddesire.com) with:

- the exact message or error code;
- whether the device is locked or unlocked;
- whether urgent access is required;
- the Wi-Fi indicator and dashboard status;
- what you already tried; and
- a photo of the screen or mechanism when safe to take one.
