---
title: "Check Lockbox Online Status"
description: "Compare the Lockbox's live connection indicator with the dashboard's delayed online status."
---

The physical Lockbox shows the live connection state. The dashboard can take up to 60 seconds to reflect it.

## Compare the indicators

| Physical Lockbox                 | Dashboard         | Meaning                                               | Action                                         |
| -------------------------------- | ----------------- | ----------------------------------------------------- | ---------------------------------------------- |
| No Wi-Fi icon or dot             | Offline           | Wi-Fi is disconnected, or the device is in deep sleep | Wake it; then reconnect Wi-Fi if needed        |
| Wi-Fi icon + yellow flashing dot | Offline or online | The device is connecting to the dashboard service     | Wait up to 60 seconds                          |
| Wi-Fi icon + solid green dot     | Online            | Fully connected                                       | No action                                      |
| Wi-Fi icon + solid green dot     | Offline           | Dashboard status is delayed or the accounts differ    | Wait 60 seconds, confirm account, refresh once |
| Wi-Fi icon + red dot             | Offline           | Joined Wi-Fi but cannot reach the internet            | Test the network or a hotspot                  |

![Lockbox Wi-Fi connected with a solid green status indicator](../img/wifi-solid-green.webp)

## Check the device

1. Wake the Lockbox.
2. Wait for the Wi-Fi icon and dot to settle.
3. Compare the display with [Status Symbols](/lockbox/using/symbols).

## Check the dashboard

1. Sign in and open **Settings → My Devices**.
2. Confirm the correct Lockbox is paired to this account.
3. Open the Lockbox page and check its online/offline indicator.
4. Allow up to 60 seconds after the device becomes green.

If the two statuses still disagree, follow [Connectivity Troubleshooting](/lockbox/support/connectivity-troubleshooting). If an active session is involved, confirm the physical lock state before sending another command.
