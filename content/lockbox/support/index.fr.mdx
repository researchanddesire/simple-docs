Commencez par le symptôme que vous pouvez voir. Si un accès urgent à la clé est impliqué, utilisez d’abord la voie d’urgence.

| Ce dont vous avez besoin | Commencez ici |
| ------------------------------------------------- | ----------------------------------------------------------------------------- |
| Accès urgent à la clé | [Safety and Emergency Access](/lockbox/safety) |
| Le déverrouillage du logiciel n'est pas disponible | [Hardware Backplate Emergency Access](/lockbox/support/emergency-backplate) |
| Le tableau de bord et l'appareil ne sont pas d'accord sur l'état en ligne | [Check Online Status](/lockbox/support/online-status) |
| Wi-Fi, la synchronisation du tableau de bord ou les commandes à distance échouent | [Connectivity Troubleshooting](/lockbox/support/connectivity-troubleshooting) |
| Un code d'erreur s'affiche à l'écran | [Lockbox Error Codes](/lockbox/errors) |
| Le support vous a demandé de réinstaller le firmware | [Flash or Recover Firmware](/lockbox/support/flashing) |

<Callout type="warn">

Ne flashez pas, ne réinitialisez pas et ne redémarrez pas à plusieurs reprises un Lockbox lorsqu'un accès urgent est requis. Utilisez d’abord le chemin d’accès d’urgence documenté.

</Callout>

## Contacter l'assistance

Envoyez un e-mail à [support@researchanddesire.com](mailto:support@researchanddesire.com) avec :

- le message exact ou le code d'erreur ;
- si l'appareil est verrouillé ou déverrouillé ;
- si un accès urgent est requis ;
- l'indicateur Wi-Fi et l'état du tableau de bord ;
- ce que vous avez déjà essayé ; et
- une photo de l'écran ou du mécanisme lorsque vous pouvez en prendre une en toute sécurité.
