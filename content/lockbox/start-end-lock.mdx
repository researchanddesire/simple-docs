# Before you lock

The Lockbox must be paired, online, and have at least one lock template. A stable green status indicator means it is ready; a blinking yellow indicator means setup is incomplete.

# Start a lock from the Dashboard

1. Charge the Lockbox and check that the release mechanism works.
2. In the [R+D Dashboard](https://dashboard.researchanddesire.com/), open **Lockbox → Templates**.
3. Choose a template and select **Lock**.
4. Choose whether the session has no keyholder or uses a connected keyholder.
5. Review every setting and confirm the lock.
6. Place the key inside and close the Lockbox when its display tells you to.

Some locks cannot be abandoned or changed after they start. Read the confirmation carefully, especially for a 24-hour lock.

# End a lock

When the session is eligible to end, follow the instructions on the Lockbox display or in the Dashboard. Confirm the unlock, retrieve the key, and leave the lid open if the inside needs to dry.

Never begin a session without a safe backup release and a plan for loss of power, connectivity, or access to the Dashboard.
