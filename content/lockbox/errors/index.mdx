---
title: "Lockbox Error Codes"
description: "Look up a Lockbox error code, assess urgency, and choose the safest first action."
---

<Callout type="warn">

If you need urgent access to the key, use [Emergency Access](/lockbox/safety) before routine troubleshooting.

</Callout>

| Code                                   | Meaning                    | Urgency                              | First action                                |
| -------------------------------------- | -------------------------- | ------------------------------------ | ------------------------------------------- |
| [E-Lock 1](/lockbox/errors/e-lock-1)   | Could not lock             | Do not rely on the device as secured | Remove obstructions and inspect alignment   |
| [E-Lock 2](/lockbox/errors/e-lock-2)   | Could not unlock           | **Access-critical**                  | Use the emergency path, then inspect        |
| [E-Lock 3](/lockbox/errors/e-lock-3)   | Backplate not detected     | Do not start the session             | Reseat and inspect the backplate            |
| [E-Lock 10](/lockbox/errors/e-lock-10) | Could not connect to Wi-Fi | Remote controls unavailable          | Confirm 2.4 GHz credentials and local state |
| [E-Lock 20](/lockbox/errors/e-lock-20) | Emergency Unlock used      | Safety event / cooldown              | Confirm access and well-being first         |

Break availability and overdue-break messages are session states, not device failures. See [Take a Break](/lockbox/using/take-a-break).

For an unlisted code, photograph the screen and email [support@researchanddesire.com](mailto:support@researchanddesire.com) with the Lockbox state and what happened immediately before it appeared.
