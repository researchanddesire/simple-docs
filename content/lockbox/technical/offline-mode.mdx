---
title: "Lockbox Offline Mode"
description: "Compare local and online Lockbox capabilities, prepare for disconnection, and verify state after reconnecting."
---

The Lockbox keeps core local functions when internet service is unavailable, but remote controls and dashboard updates require a connection.

## Capability matrix

| Capability                  | Offline behavior                                       | After reconnection                                                |
| --------------------------- | ------------------------------------------------------ | ----------------------------------------------------------------- |
| Local timed lock            | Timer continues on the device                          | Dashboard state can update                                        |
| Local lock/unlock mechanism | Available from the physical device                     | Physical state remains authoritative                              |
| Device menus and buttons    | Available                                              | No special action expected                                        |
| Sleep and wake              | Available                                              | Wi-Fi reconnects after wake when credentials remain valid         |
| Software Emergency Unlock   | Available locally when the session has not disabled it | Event can sync to the dashboard                                   |
| Keyholder commands          | **Unavailable**                                        | Current server/device state must reconcile; confirm on the device |
| Dashboard changes           | **Unavailable to the device**                          | May arrive after reconnection; do not assume order or timing      |
| Public voting               | New votes cannot reach the device                      | Check the active session after reconnection                       |
| Activity history            | Dashboard may be stale                                 | Events can appear after reconnection                              |
| Firmware updates            | Unavailable                                            | Resume only on stable power and network                           |

<Callout type="warn">

An offline Lockbox cannot receive a remote Keyholder unlock. Before any session that may lose internet, confirm local Emergency Unlock availability and keep the hardware backplate procedure available.

</Callout>

## Time display

The current documentation says a local timer continues even when the device cannot synchronize network time. The screen may show **Connect Wi-Fi to see time remaining** until time is synchronized again.

Do not infer that a hidden or unavailable countdown means the session ended. Confirm the physical lock state and use emergency access when needed.

## Local locks and dashboard-managed locks

| Session type           | Created where                               | Offline control                                                                          |
| ---------------------- | ------------------------------------------- | ---------------------------------------------------------------------------------------- |
| Local lock             | Physical Lockbox                            | Runs on the device; dashboard does not manage it                                         |
| Dashboard-managed lock | Dashboard, then synchronized to the Lockbox | Continues with the last settings held by the device; remote changes require reconnection |

## Test before relying on offline use

1. Complete pairing and Wi-Fi setup while unlocked.
2. Run a short online test lock and normal unlock.
3. Confirm local Emergency Unlock and review [hardware emergency access](/lockbox/support/emergency-backplate).
4. Start another short test, disconnect the network, and confirm the expected local screen and timer behavior.
5. Reconnect and verify the physical device and dashboard reach the same state.

<Callout type="info">

Firmware and dashboard reconciliation behavior can change. This guide does not promise how conflicting offline and online changes are ordered. Avoid making competing changes while offline and verify the final physical state after reconnection.

</Callout>

## Recover after a disconnection

1. Wake the Lockbox; deep sleep disables Wi-Fi.
2. Wait for the status indicator to settle.
3. Use [Check Online Status](/lockbox/support/online-status).
4. Compare the physical state with the dashboard after its update interval.
5. If they disagree, do not start another lock. Follow [Connectivity Troubleshooting](/lockbox/support/connectivity-troubleshooting).
