## Segment Types

Training sessions are built from segments. Each segment type offers a different training approach to help develop skills progressively.

<CardGroup cols={2}>
  <Card title="Repetition" icon="repeat" href="./repetition">
    Practice consistent depth and rhythm with repeated strokes at a set pace.
  </Card>

  <Card title="Endurance" icon="stopwatch" href="./endurance">
    Build stamina by holding at depth for extended periods.
  </Card>

  <Card title="Freeform" icon="wand-magic-sparkles" href="./freeform">
    Train with dynamic, self-paced patterns targeting average RPM.
  </Card>

  <Card title="Bounce" icon="arrows-up-down" href="./bounce">
    Master controlled rhythm with gradual movements in both directions.
  </Card>
</CardGroup>

!!! tip
Start with Repetition segments to build foundational skills, then progress to Endurance and Freeform as comfort and confidence grow. Bounce is more advanced—try it once you've mastered Repetition.
